## 先判斷「沒記到」能證明多少

按上方「載入不可判定」：PLC 每 100 ms 取樣一次，低壓只持續 50 ms。事件可能完整落在兩次取樣之間，所以「紀錄沒有低壓」不能寫成「沒有低壓」。若兩設備事件只差 20 ms，而每台牆上時間誤差都是 ±100 ms，兩事件的相對不確定度是 ±200 ms；報告只能寫時間重疊，不能宣稱誰先發生。

再按「載入可排序案例」：10 ms 取樣對 50 ms 低壓，理想週期模型保證至少取得一筆；事件差 250 ms，大於兩台合計的 ±40 ms 相對不確定度，可以依目前誤差判 B 較晚。

這是離線時間覆蓋模型，不連接 UPS、FX5U 或交換器。它假設固定週期且沒有排程延遲；真實系統仍要記錄採樣抖動、資料傳送、設備重啟與時鐘校正。

## 先畫供電鏈，再收事件

將 AC 輸入、AC/DC 電源、DC UPS、共同母線、每個分路、FX5U、遠端 I/O 與交換器分開。每個方塊至少標出：

- 電源來源和保護器；
- 可觀測的電壓、接點或內部狀態；
- 原始採樣週期與資料更新週期；
- 裝置時間來源、解析度及最大誤差；
- 重啟後時間是否會重設。

畫面每秒更新，不代表電壓每秒量一次；UPS 面板正常，也不代表最遠分路沒有瞬間壓降。ping 中斷只證明網路路徑失去回應，不能單獨證明交換器掉電。

## 一個六筆事件的判讀案例

| 來源       | 原始事件       | 裝置時間     | 已知限制                        |
| ---------- | -------------- | ------------ | ------------------------------- |
| UPS 接點   | 轉入電池       | 10:00:00.800 | 接點記錄誤差 ±100 ms            |
| FX5U       | 最後有效掃描   | 10:00:00.820 | 100 ms 電壓取樣                 |
| 電壓記錄器 | 末端低壓 50 ms | 10:00:00.850 | 1 ms 取樣，同步誤差 ±5 ms       |
| 交換器     | link down      | 10:00:00.910 | 時鐘誤差 ±150 ms                |
| FX5U       | 啟動標記       | 10:00:02.400 | 重啟後由上位機讀取              |
| HMI        | 第一筆新資料   | 10:00:03.100 | 通訊恢復時間，不是 PLC 上電時間 |

這組合成資料能確定記錄器看到了末端低壓，也能確定 HMI 的第一筆新資料晚於 PLC 啟動標記。它不能只靠顯示時間證明 UPS 轉移造成 FX5U 停止，因 UPS、PLC、交換器的誤差範圍互相重疊，而且 PLC 的 100 ms 取樣可能漏掉 50 ms 低壓。

### 把觀察與推論分欄

| 觀察                  | 可以寫的推論       | 還缺的證據             |
| --------------------- | ------------------ | ---------------------- |
| UPS 接點切換          | UPS 狀態有變化     | 切換期間母線波形       |
| 記錄器量到 50 ms 低壓 | 該測點確有低壓     | 其他分路同步波形       |
| FX5U 後來出現啟動標記 | 控制器曾重新初始化 | 精確掉電與上電時刻     |
| 交換器 link down      | 網路連線中斷       | 交換器端電壓與內部事件 |

## 建立能重現的測試

1. 先保存正常負載、電池狀態、各分路電流和所有時間來源。
2. 定義批准的 UPS 轉移方式、停測條件與復原步驟；不任意拔帶電線。
3. 在 UPS 輸出、共同母線、FX5U 端與交換器端同步記錄，保留原始檔。
4. 分別測正常負載、代表性啟動負載與單一分路變化，每次只改一項。
5. 報告原始時間、校正後時間、解析度與不確定度，不覆寫原始值。

如果事件差小於兩個裝置誤差的合計，就標成時間重疊。若低壓短於取樣週期且沒有更快記錄器，標成可能漏採。這兩種「不可判定」都是有效結論，不應用畫面沒有告警補成正常。

## 與容量、壓降分開驗收

電池標稱 4 Ah 不能直接證明 2 A 可支撐兩小時；可用容量還受溫度、老化、放電率、截止電壓和轉換效率影響。供電時間要用指定 UPS／電池的放電曲線與核准負載測試。

同樣地，UPS 輸出 24.1 V、FX5U 端 23.6 V、遠端 I/O 端 21.8 V，應先處理各段壓降，不能只把 UPS 狀態標為正常。可用上方事件模型判讀時間證據，再用支路文章的三點量測定位電壓損失。

本文未執行 UPS 轉移或 FX5U 實機測試。上方結果是確定性的離線規則；現場結論必須附原始波形、取樣設定與時鐘誤差。
