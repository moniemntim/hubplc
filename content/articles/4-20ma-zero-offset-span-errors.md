## 先完成一個判讀，再決定查哪裡

本篇處理「數字持續更新、來源品質正常，但顯示不準」的情況。若是 0 mA、品質失效或超量程，先看[來源品質與超量程判讀](/articles/4-20ma-scaling-open-overrange-diagnostics)；若還沒完成縮放，先做[類比換算操作課](/articles/plc-analog-scaling-pressure-temperature-level)。不要把三種問題都用加減一個補償值處理。

頁面上方的比對器採固定 **0–10 bar** 範例，不接設備。所有載入資料都是合成數字，以下結果是算式重現，沒有硬體實測或校正合格證明。其他量程不能直接把數字填進來，因為基準點和百分比的分母也要改。

1. 點「載入固定偏移」，保留判讀容差 `0.05 bar`。
2. 五個讀值為 `0.4、2.9、5.4、7.9、10.4 bar`；誤差應全部為 `+0.4 bar`，也就是 `+4% span`。
3. 應看到「固定偏移線索」、端點倍率 `1`、最大直線殘差 `0`。
4. 將基準 5 bar 的讀值改為 `5.9`。兩端沒變，但中間點殘差成為 `+0.5 bar`，結論改成「中間點偏離端點直線」。此時只調零點不能解釋全部資料。
5. 清空任何讀值：應顯示錯誤並撤下判讀表，不拿舊結果當成新結果。再載入範例即可復原。

## 四組數字，各自引導不同的下一步

以下基準依序為 `0、2.5、5、7.5、10 bar`，容差均為 `0.05 bar`。這個容差是本課的辨識門檻，不是儀表精度或專案允收值。

| 載入案例     | 五個讀值（bar）               | 應看到的關鍵結果              | 優先核對                               |
| ------------ | ----------------------------- | ----------------------------- | -------------------------------------- |
| 固定偏移     | 0.4 / 2.9 / 5.4 / 7.9 / 10.4  | 低點 +0.4、倍率 1             | 額外加值、零點設定，以及上游是否已偏移 |
| 跨度差       | 0 / 2.75 / 5.5 / 8.25 / 11    | 低點 0、倍率 1.1、高點誤差 +1 | 量程上限、單位、是否重複縮放           |
| 中間點偏離   | 0 / 2.8 / 5.6 / 7.8 / 10      | 兩端正確，中點殘差 +0.6       | 穩定時間、非線性轉換、方向差與量測鏈   |
| 偏移加跨度差 | 0.2 / 2.45 / 4.7 / 6.95 / 9.2 | 低點 +0.2、倍率 0.9           | 不只一個設定可能有差異，需逐段比對     |

同一形狀可能來自不同位置。看到固定偏移，不能直接宣告傳送器零點壞了；看到中間點偏離，也不能只憑五個數字斷定感測器非線性。

## 先說清楚：你量的是哪一段？

### 案例 A：對 PLC 類比輸入注入已知電流

本例的名義對應為 `4、8、12、16、20 mA` → `0、2.5、5、7.5、10 bar`。先依模組與校正器手冊確認端子、供電及 source/simulate 模式；兩者不是任意互換。注入會改變控制程式看到的輸入，必須依現場程序隔離會受影響的輸出，再進行測試。

記錄每一點的校正器輸出、PLC 原始值、PLC 工程值與 HMI 顯示值。原始值比例以實際模組和通道設定為準，本篇不假設通用 counts 範圍。

假設確認注入 12 mA，PLC 工程值為 5.0 bar，HMI 卻是 5.4 bar；同樣差異也出現在另外四點。先查 HMI 綁定、額外換算或補償。若 PLC 工程值本身已是 5.4 bar，則向輸入設定及 PLC 縮放方向追查，還要對照原始值才能縮小位置。

這項測試涵蓋接入點之後的量測鏈，**沒有測到被取代的壓力傳送器**。校正器面板設定值也不能取代適用的準確度、負載能力與有效校正紀錄。

### 案例 B：用獨立壓力基準檢查整條量測鏈

保留傳送器，施加可追溯的壓力基準，同步記錄基準壓力、傳送器電流、PLC 與 HMI 讀值。基準和被測物須使用一致的表壓／絕壓定義與單位；施壓、洩壓及接管依設備程序操作。

例如基準為 5.0 bar，傳送器電流觀察到 11.2 mA，而 PLC 顯示 4.5 bar。依本例線性設定，11.2 mA 對應 4.5 bar，PLC 的換算在這一點相符；應先核對壓力基準、傳送器設定及中間元件。直接在 PLC 加 0.5 bar，只會把尚未確認的差異藏起來，也不知道其他點是否會被改壞。

## 如何留下可重做的五點紀錄

用上升方向 `0 → 2.5 → 5 → 7.5 → 10 bar` 做一組，再用下降方向 `10 → 7.5 → 5 → 2.5 → 0 bar` 做另一組。每點達到事先約定的穩定條件才記錄，保留等待時間；沒有適用所有傳送器的固定秒數。

每組表至少填入：

- 測試日期、人員、輸入方式（電流注入或實際壓力）、測試接入位置。
- 基準儀器識別、量程、校正狀態；被測模組／傳送器型號與設定版本。
- 測試方向、基準值、實際電流、PLC 原始值、PLC 工程值、HMI 值、來源品質及穩定時間。
- 原設定、任何調整內容、調整前後各一整組結果；未量到的欄位留空，不填零。

比對器每次輸入同一方向、同一位置的五個讀值，按基準由小到大排列。不要把上升和下降的數字混成一組。如果同一基準的上下行讀值不同，先保存差異並重做，核對穩定條件與基準；單次五點不足以分辨遲滯、漂移或偶發波動。

## 表中的誤差、倍率與殘差怎麼算？

本課定義誤差為「讀值 − 基準」，正號表示讀高。量程跨度是 `10 − 0 = 10 bar`，所以 `+0.1 bar / 10 bar × 100 = +1% span`，不是相對當下讀值的 1%。在零點也不需要除以零。

端點倍率為 `(高點讀值 − 低點讀值) / 10`。固定偏移範例是 `(10.4 − 0.4) / 10 = 1`；跨度差範例是 `(11 − 0) / 10 = 1.1`。這是在描述資料，不是建議把倍率直接寫進 PLC。

端點直線在任意基準 x 的預測值為 `低點讀值 + 倍率 × x`；殘差為「讀值 − 預測值」。兩端殘差依定義為零，因此一定要看中間三點。這不是最小平方法擬合，也不能直接代替設備手冊採用的非線性定義。

比對器先看五點誤差是否都在容差內；若否，再看中間點是否偏離端點直線；最後依低點誤差與高低點誤差差值給出偏移／跨度線索。計算僅加 `1e-9 bar` 浮點比較保護，沒有納入量測不確定度。讀值限於 ±1,000,000 bar、判讀容差限於 0.000001–10 bar，這是工具輸入邊界，不是建議量測範圍。

## 哪些情況還不能結案？

「五點誤差均在選定容差內」只說明這五個輸入與你選的門檻關係；把容差放大就會改變分類，不會讓設備更準。正式驗收要另外指定允收規格、基準能力、環境和不確定度處理方式。

若來源品質失效、讀值被限幅、時間不同步或持續漂移，先解決這些條件再做誤差判讀。修正設定後，重新量整組上下行資料，確認沒有把中點修好卻使兩端變差；保留調整前後記錄才有比較依據。
