本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會用絕對值表示數字離零有多遠，並保留原始數據的正負方向。透過負差額、正差額、零及小數的例子，你會看到負數轉成正值、正數與零維持原值；完成後，能區分差額大小與增加或減少的方向，避免把正的結果誤認成獲利或改善。

## 什麼時候會用到

- 核對實測值與目標值的差異大小時，將已有正負號的差額轉成非負數，方便依偏差幅度比較批次；原差額仍要保留，以供追查過高或過低。例如大小同為十八的正負差額，處理優先順序可能相同，但修正方向相反，報表應保留兩種資訊而不是只留大小。

- 比較溫度偏離基準或庫存盤點的差距時，若問題只關心偏離多少，可另算差距大小。若還要知道短缺或過量，必須回看原始正負號。

## 適用版本

- Microsoft 官方適用版本列出 Microsoft 365、Excel 2024、Excel 2021、Excel 2019 與 Excel 2016；本課用一般儲存格公式即可完成。

- 本課使用半形逗號分隔參數，輸入後直接按 Enter。若系統地區設定要求分號，請依當地 Excel 的參數提示調整分隔符號。

## 先準備範例資料

開啟空白活頁簿，依下表輸入對應儲存格。表中「（空白）」代表儲存格留空，請勿輸入括號內的文字。

| 列 | A | B |
| --- | --- | --- |
| 1 | 項目 | 實測差額 |
| 2 | 批次甲 | -18 |
| 3 | 批次乙 | 12 |
| 4 | 批次丙 | 0 |
| 5 | 批次丁 | -2.5 |
| 6 | 批次戊 | 2.5 |
| 7 | 批次己 | -40 |
| 8 | 批次庚 | 8 |

- 本課 A1:B8 是合成的批次差額紀錄。A 欄是批次，B 欄已經是算好的差額；主公式只讀取 B2 的 -18，不必先做其他運算。

- B2、B5、B7 是負差額，B3、B6、B8 是正差額，B4 是數字 0。輸入時保留全部負號，不能為了取得正結果而先改掉原資料。

- B5 的 -2.5 與 B6 的 2.5 大小相等但方向相反。小數點請用半形；格內不加「元」「度」或其他單位，以免混成文字。

- B2:B8 與 E2 可以用數值格式顯示一位小數。E2 顯示 18.0 與數值 18 相同；本課沒有要求取整，也沒有透過格式刪除小數。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=ABS(B2)
```

輸入位置：E2　　正確結果：18

## 語法與引數

```excel
=ABS(number)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

number　必要參數，指定要求絕對值的實數。本課使用含負值的 B2；也可使用正數或零。只有這一個參數，沒有位數或方向選項。指向儲存格時，函數讀取的是數值內容，不會因為將文字顏色設成紅色就把正值視為負值；判斷方向要看實際數字。

公式使用半形標點；部分地區設定以分號分隔引數，請依 Excel 的提示調整。

## 照著做並核對畫面

1. 新增空白工作表，選取 A1，輸入 A1:B8 的標題與七筆資料。完成後選 B2，在公式列確認原值為 -18。
2. 選 B2:B8，設成數值、一位小數；確認 B5、B6 能看見小數點及正負差異，B4 確實是數字零。
3. 選 E1，輸入「批次甲差額大小」，再選 E2。將 E2 設為數值、一位小數，結果放在獨立位置以保留原始差額。
4. 在 E2 的公式列輸入 =ABS(B2)，使用半形等號及括號，只放一個參數 B2，檢查完畢後按 Enter。
5. 重新選 E2，應顯示 18.0；公式列應顯示 =ABS(B2)。回頭確認 B2 仍為 -18，並口頭說明結果只表示離零十八個單位。

## 結果解讀

1. 先讀出 B2 是 -18。負號表示原差額在零的左側，這個方向資訊保留在 B2，不從原始資料刪除。

2. 考慮 -18 到 0 的距離，大小為 18 個單位；距離不會是負十八，所以要以非負值表示。

3. ABS 回傳 18。這不是把差額改成多出十八，也沒有進位或捨去，只是取其大小。

4. E2 以一位小數格式顯示 18.0。若後續要查原差額是短缺或超出，仍需看 B2 的 -18。這也說明為什麼主題要另放結果欄：大小與方向解答不同問題，各自有保存價值，不能互相取代。

- 正數的絕對值維持原值，零的絕對值也是零。因此不能把此函數理解成每次都翻轉正負號；若原本是 12，答案仍為 12。可以用三個小問題自查：數字是否為負、離零多遠、結果是否非負；只把每個數都乘以負一會把原本正值變負，並不正確。

- 絕對值會把同等大小、相反方向的值映成同一結果，例如 -2.5 與 2.5 都得到 2.5。僅從結果不能恢復原始正負方向。

- 本函數不會幫你判斷資料輸入是否合理，也不會自動四捨五入。應同時保留原值、單位與情境，避免把清楚的數字誤作不正確的結論。

## 常見錯誤

1. 主題結果顯示 -18。

原因：可能只引用了 B2，或把原差額直接貼進 E2。　處理：選 E2，檢查公式列必須是 =ABS(B2)；僅顯示負號的自訂格式也應先改回一般數值格式核對。

2. E2 顯示 #VALUE!。

原因：B2 可能是帶單位或無法轉成數字的文字。　處理：將 B2 恢復為半形 -18，單位另外放標題；公式確認引用 B2 而不是 A2。

3. 原始負號消失，無法再判斷差額方向。

原因：將正的結果貼回 B 欄或先把負值手動改正。　處理：依原表恢復 B 欄，在 E2 單獨顯示絕對值；不要用結果覆蓋尚需追查方向的來源。

## 自己試一次

先遮住解答，試著自己輸入公式並預測結果。每題都從上方的原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　零差額

先恢復原始 A1:B8；E1 輸入「批次丙差額大小」，在 E2 計算 B4。

參考公式：

```excel
=ABS(B4)
```

正確結果：0

解答 1　B4 是 0，表示本題原差額為零，離零距離也是零。

解答 2　E2 應顯示 0.0；本函數不會把零改成正一或空白。

### 練習 2　相反方向同大小

先恢復原始 A1:B8；E1 輸入「批次戊差額大小」，在 E2 計算 B6。

參考公式：

```excel
=ABS(B6)
```

正確結果：2.5

解答 1　B6 是正的 2.5，絕對值仍是 2.5。

解答 2　它與變化二的 -2.5 得到相同答案，但兩筆原差額方向不同，要保留 B 欄才可辨識。

### 練習 3　更換差額

先恢復原始 A1:B8，只把 B2 改為 -7.25；E1 保留原標題，在 E2 使用原公式，結果格式改為兩位小數。

參考公式：

```excel
=ABS(B2)
```

正確結果：7.25

解答 1　新差額 -7.25 到零的距離是 7.25，因此公式無須更換來源格。

解答 2　E2 應顯示 7.25；原本一位小數格式可能只顯示 7.3，所以本題要改成兩位核對。
