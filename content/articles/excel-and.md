檢查訂單是否同時「已付款」與「已備貨」。兩個條件都成立才顯示 TRUE，代表符合本例的出貨檢查條件。

## 先準備範例資料

開啟空白活頁簿，依下表把資料輸入對應儲存格。A、B 等是欄名；1、2 等是列號。

| 列 | A | B | C |
| --- | --- | --- | --- |
| 1 | 訂單編號 | 已付款 | 已備貨 |
| 2 | D101 | 是 | 是 |
| 3 | D102 | 是 | 否 |
| 4 | D103 | 否 | 是 |

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=AND(B2="是",C2="是")
```

正確結果：TRUE

語法：

```excel
=AND(logical1,[logical2],...)
```

| 引數 | 代表什麼 |
| --- | --- |
| logical1 | 第一個判斷條件。本例 B2="是"，檢查訂單是否已付款。 |
| logical2, ... | 其餘判斷條件。本例 C2="是"，檢查訂單是否已備貨。全部條件都成立，最後結果才是 TRUE。 |

公式請使用英文名稱及半形標點；若系統以分號分隔引數，請依 Excel 提示改用分號。語法中的方括號表示選填，不必輸入。

## 照著做並核對畫面

1. 開啟一張空白工作表，從 A1 開始輸入範例表格，資料會占用 A1:C4。
2. 在 E1 輸入「付款及備貨皆完成」，再點選 E2。
3. 在 E2 輸入 =AND(B2="是",C2="是")，然後按 Enter。
4. 確認 E2 顯示 TRUE；B2 與 C2 都是「是」，表示兩個條件同時成立。

B2="是" 與 C2="是" 會各自得到判斷結果。兩個結果都成立時，AND 傳回 TRUE；只要其中一個不成立，就傳回 FALSE。TRUE 表示本例的全部條件成立，FALSE 表示至少一項未成立。

## 常見錯誤

- 只輸入 B2、C2，卻沒有寫出要比較的文字。本例的儲存格內容是「是／否」，應明確寫成 B2="是"、C2="是"。
- 以為任一條件成立就會得到 TRUE。此函數要求所有列出的條件都成立。
- 期待公式直接顯示「可出貨」。此函數本身的結果是 TRUE 或 FALSE，本課不把結果轉換為其他文字。

## 自己試一次

保留 A1:C4 不變，在 E3 輸入公式，檢查第 3 列的 D102 訂單是否已付款且已備貨。

參考答案：

```excel
=AND(B3="是",C3="是")
```

結果：FALSE。B3 為「是」，但 C3 為「否」，其中一項未成立，因此 E3 顯示 FALSE。
