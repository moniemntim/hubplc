本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會先用一個條件選出符合的紀錄，再平均那些列的數值。你會分清楚檢查組別的欄位與實際平均的分數欄，記住條件範圍、條件、平均範圍的順序，並能逐列核對納入哪些分數、為何只除以三筆。

## 什麼時候會用到

- 班級資料同時包含多個組別時，快速計算指定組別的平均分數；不必刪除其他組別，也不必改動原表的排列順序。

- 需要只看達到某個數字門檻的紀錄時，例如分數至少八十分，讓條件與平均都使用同一欄，檢查符合門檻的整體表現。

## 適用版本

- 本課可在 Microsoft 365、Excel 2024、Excel 2021、Excel 2019 與 Excel 2016 使用，官方函數頁列有這些版本。

- 本課使用一般儲存格參照，輸入完成按 Enter 即可；不需額外增益集，也不用特殊陣列按鍵。

## 先準備範例資料

開啟空白活頁簿，依下表輸入對應儲存格。表中「（空白）」代表儲存格留空，請勿輸入括號內的文字。

| 列 | A | B |
| --- | --- | --- |
| 1 | 組別 | 分數 |
| 2 | 北組 | 80 |
| 3 | 南組 | 60 |
| 4 | 北組 | 90 |
| 5 | 西組 | 70 |
| 6 | 北組 | 100 |
| 7 | 南組 | 80 |
| 8 | 西組 | 90 |

- A1:B8 是原始表，A2:A8 放組別，B2:B8 放分數。A1、B1 是標題，不納入主公式；同一列的組別與分數屬於同一筆紀錄。

- 北組在 A2、A4、A6，對應分數為 B2 的80、B4的90、B6的100。文字請完全照表輸入，避免在北組前後加入空格。

- B欄請輸入純數字，不要輸入「80分」或在數字前加單引號。這份表沒有空白分數，主題目的分母因此明確是三筆。

- 主公式第三個參數是平均範圍。請先記「在哪欄找、找什麼、平均哪欄」，不要看到函數名稱有平均兩字，就把分數範圍放到最前面。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=AVERAGEIF(A2:A8,"北組",B2:B8)
```

輸入位置：E2　　正確結果：90

## 語法與引數

```excel
=AVERAGEIF(range,criteria,[average_range])
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

range　必要。用來檢查條件的範圍，本例是A2:A8。當你指定第三個參數時，這裡只負責判斷哪些列符合，不是實際拿來平均的分數。

criteria　必要。要套用的條件，本例是文字"北組"，必須用半形雙引號包住。也可填數字、含比較符號的文字條件，或一個存放條件的儲存格。

[average_range]　選填。實際平均的數值範圍，本例為B2:B8。省略時，直接平均第一個range內符合條件的數字；方括號只代表可省略，不是要輸入的符號。

公式使用半形標點；部分地區設定以分號分隔引數，請依 Excel 的提示調整。

## 照著做並核對畫面

1. 新增一張空白工作表，點選 A1，依資料表輸入到 B8。第一列是標題，第2至第8列才是七筆紀錄；數字欄只輸入數字，單位留在標題或說明中。
2. 在公式列左側的名稱方塊輸入 A1:B8，按 Enter 檢查資料的位置。特別核對A4是北組、B4是90，避免文字與分數錯開一列。 若貼上後擠在同一格，先重新分欄輸入，確認每個欄位各占一欄。
3. 點選 E1，輸入「北組平均分數」。再點選 E2，確保結果放在原始資料右側，不覆蓋資料，也不把 E2 自己包含在計算範圍內。
4. 切換半形英數輸入，在 E2 完整輸入 =AVERAGEIF(A2:A8,"北組",B2:B8)。輸入完成先核對函數拼字、冒號與左右括號，再按 Enter；請勿把語法說明中的方括號輸入公式。
5. 確認 E2 顯示 90，再重新點選 E2。公式列應顯示 =AVERAGEIF(A2:A8,"北組",B2:B8)，儲存格則顯示答案；若答案不同，先核對資料與範圍，不要直接把答案數字覆寫進 E2。

## 結果解讀

1. 先讀A2:A8，只標記等於北組的第2、4、6列；第3、5、7、8列不參與本次計算。

2. 沿同一列移到B欄，取得80、90、100。不能拿A欄文字來平均，也不能把北組的列數當成分數。

3. 三個分數相加為270，再除以符合條件且有數字的3筆，270÷3=90；E2顯示北組的平均分數。

- AVERAGEIF的順序是條件範圍、條件、平均範圍，平均範圍在第三位；AVERAGEIFS則把平均範圍放第一位。兩者不能只替換名稱而保留參數順序，本課只操作單一條件的這一種寫法。

- 符合條件的平均格若真正空白，該格不參與平均；數字0則會參與。若沒有任何可平均的符合紀錄，會顯示#DIV/0!，不是平均值為零。

- Excel允許第三個範圍形狀與第一個不同，會依起點及第一個範圍的形狀取值；初學時仍一律使用相同起訖列，避免不知不覺算到別列。驗算時先列出符合的儲存格，再算總分及筆數；不要先算全部七筆的總分，再用北組人數相除。條件只選擇原始列，不會改動資料的內容或排列。

## 常見錯誤

1. 出現#DIV/0!

原因：條件打成不存在的組別，或符合組別的分數都沒有可計算數字。　處理：選取A2、A4、A6確認北組文字，再檢查B2、B4、B6是數字；重新輸入主公式。

2. 答案不像北組平均

原因：把分數範圍放在第一個參數，或平均範圍漏掉第三個位置。　處理：在E2公式列依序讀出A2:A8、"北組"、B2:B8，確認各自的工作。

3. 出現#NAME?或公式無法接受

原因：文字條件缺少引號，或混用了全形括號、逗號。　處理：切換半形輸入，完整重打主公式；引號只包北組，不包住儲存格範圍。

## 自己試一次

先遮住解答，試著自己輸入公式並預測結果。每題都從上方的原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　指定西組

先恢復本課原始資料。在E2求西組平均分數，資料不修改。

參考公式：

```excel
=AVERAGEIF(A2:A8,"西組",B2:B8)
```

正確結果：80

解答 1　西組在第5與第8列，分數為70與90。

解答 2　兩筆160÷2=80，第三個參數仍指定B2:B8。

### 練習 2　更新北組分數

先恢復本課原始資料。只把B2改成50，在E2重新求北組平均。

參考公式：

```excel
=AVERAGEIF(A2:A8,"北組",B2:B8)
```

正確結果：80

解答 1　北組位置未改，仍取第2、4、6列；新分數為50、90、100。

解答 2　合計240除以3得80，原公式不必重選範圍。

### 練習 3　排除80分本身

先恢復本課原始資料。在E2平均嚴格大於80的分數，使用兩個參數。

參考公式：

```excel
=AVERAGEIF(B2:B8,">80")
```

正確結果：約 93.333333；Excel 顯示的小數位數取決於儲存格格式。

解答 1　符合者是90、100、90，80不符合大於80。

解答 2　280÷3=93.333333…；顯示的小數位可能有限，但不是計算錯誤。
