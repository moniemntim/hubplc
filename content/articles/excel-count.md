本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

統計培訓測驗中已輸入數字成績的筆數；文字備註與空白不算，零分仍要算。

## 先準備範例資料

開啟空白活頁簿，依下表把資料輸入對應儲存格。A、B 等是欄名；1、2 等是列號。

| 列 | A | B |
| --- | --- | --- |
| 1 | 學員 | 測驗成績 |
| 2 | 小安 | 88 |
| 3 | 怡君 | 缺考 |
| 4 | 志明 | 0 |
| 5 | 佳玲 | （空白） |
| 6 | 文傑 | 75 |
| 7 | 美玲 | 待補考 |

「（空白）」表示不要輸入任何內容，也不要輸入這段文字。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=COUNT(B2:B7)
```

正確結果：3

語法：

```excel
=COUNT(value1, [value2], ...)
```

| 引數 | 代表什麼 |
| --- | --- |
| value1 | 第一個要檢查的儲存格或範圍。本例使用成績欄 B2:B7。 |
| [value2], ... | 可省略的其他儲存格或範圍。方括號表示選填，不用把方括號輸入公式。 |

公式請使用英文名稱及半形標點；若系統以分號分隔引數，請依 Excel 提示改用分號。語法中的方括號表示選填，不必輸入。

## 照著做並核對畫面

1. 在空白工作表的 A1:B7 輸入表格資料，B5 不輸入任何內容。
2. 在 E1 輸入「數字成績筆數」，再按一下 E2。
3. 在 E2 輸入 =COUNT(B2:B7)，再按 Enter。
4. 確認 E2 顯示 3，逐一核對 B2、B4、B6 這三個數字儲存格。

B2 的 88、B4 的 0、B6 的 75 各算一筆，所以結果是 3。B3 與 B7 是文字，B5 是真正空白，都不計入。結果代表數字的筆數，不是總分，也不是及格人數。Excel 正確辨識的日期與時間也是數值，放入統計範圍時也會被計入。

## 常見錯誤

- 把 0 分排除：0 也是數字，本例的 B4 必須算一筆。
- 數字前加了半形單引號，例如輸入 '88：這會把成績存成文字，在本例的範圍統計中不會計入。
- 以為有寫「缺考」也算成績：本例只計算數字儲存格，文字備註與真正空白都不計入。

## 自己試一次

佳玲的成績補上了，把 B5 改為數字 66。已輸入的數字成績共有幾筆？

參考答案：

```excel
=COUNT(B2:B7)
```

結果：4。新增了一個數字儲存格，筆數由 3 增為 4；其他兩格文字仍不計入。
