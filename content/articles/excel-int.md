學會將數字向下取成最接近的整數，並用數線判斷負數為什麼不能直接刪掉小數。本課以負三點二為主例，搭配正數、負整數與接近零的資料；完成後，你能清楚說明答案必須不大於原值，並確認零位小數格式與真正取整是不同操作。

## 什麼時候會用到

- 將一批測量數字歸入以整數為下界的區間，例如 3.8 歸入從 3 開始的區間；若包含負值，必須同樣沿數線向較小方向選整數。區間的起點與終點要有一致定義，否則相鄰資料可能被重複分類；取整只能執行你選定的數學規則。

- 處理非負的資源數量時，估計有多少完整單位，例如 3.8 個單位只能提供 3 個完整單位。套用到負值前，先確認業務規則是否也要求向下取整。

## 適用版本

- Microsoft 官方適用版本列出 Microsoft 365、Excel 2024、Excel 2021、Excel 2019 與 Excel 2016；本課用一般儲存格公式即可完成。

- 本課使用半形逗號分隔參數，輸入後直接按 Enter。若系統地區設定要求分號，請依當地 Excel 的參數提示調整分隔符號。

## 先準備範例資料

開啟空白活頁簿，依下表輸入對應儲存格。表中「（空白）」代表儲存格留空，請勿輸入括號內的文字。

| 列 | A | B |
| --- | --- | --- |
| 1 | 項目 | 測試數值 |
| 2 | 負數小數 | -3.2 |
| 3 | 正數小數 | 3.8 |
| 4 | 負整數 | -3 |
| 5 | 零值 | 0 |
| 6 | 接近零負數 | -0.2 |
| 7 | 接近零正數 | 0.9 |
| 8 | 整數 | 12 |

- 原始資料位於 A1:B8；A 欄是辨識用途的標籤，B 欄是純數字。主公式只用 B2，其他列供獨立變化與練習，不會自動一併計算。

- B2 是 -3.2，B3 是 3.8。負號要用半形，不能在前方加單引號，也不要輸入「負三點二」或「3.8 單位」等文字。

- B4 為 -3，B5 為 0，B6 為 -0.2，B7 為 0.9，B8 為 12。這些特殊值分別測試整數不變、零不變，以及零左右兩邊的取整方向。

- B2:B8 可以用數值格式顯示一位小數；E2 設為數值、零位小數。B4 顯示 -3.0 時仍是整數 -3，不代表資料新增了額外精度。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=INT(B2)
```

輸入位置：E2　　正確結果：-4

## 語法與引數

```excel
=INT(number)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

number　必要參數，指定要向下取整的實數，可直接填數字或儲存格參照。本例是 B2；正數、負數、零皆可使用，並沒有指定保留位數的第二個參數。儲存格參照可以讓結果隨原值更新；直接把 -3.2 寫在公式中也能計算，但本課保留來源格，較容易核對資料。

公式使用半形標點；部分地區設定以分號分隔引數，請依 Excel 的提示調整。

## 照著做並核對畫面

1. 開啟空白工作表，選 A1，逐列建立 A1:B8。完成後點 B2，在公式列核對是 -3.2，並確認 B6 是 -0.2。
2. 選取 B2:B8，設為數值、一位小數，讓正負號與小數位置容易比較。不要在此時刪除小數部分，否則主題的原始資料會改變。
3. 選 E1，輸入「向下取整結果」；再選 E2，將它設成數值、零位小數，確認結果儲存格與 B 欄資料分開。
4. 點選 E2 的公式列，輸入 =INT(B2)，確認只有一個參數 B2，不要加逗號或第二個零，再按 Enter。
5. 重新選 E2，確認顯示 -4，公式列保留 =INT(B2)。回頭檢查 B2 仍是 -3.2，並用 -4 小於 -3.2 的關係驗證答案。

## 結果解讀

1. 先在數線上定位 B2 的 -3.2，它在 -4 與 -3 之間；數線越往左數字越小，負號不能忽略。

2. 要找不大於 -3.2 的整數。-3 比 -3.2 大，因此不能選；-4 小於 -3.2，符合向下的要求。

3. 符合要求的整數雖然還有 -5、-6 等，但 -4 最接近原值，所以結果為 -4，不會繼續降到更遠的整數。因此答案必須同時符合兩件事：不超過原值，且在符合條件的整數之中最大，缺少任一條件都不能唯一決定結果。

4. E2 寫入數字 -4，B2 原值保持 -3.2。只把 -3.2 的顯示小數位數減少，不能取代上述計算規則。

- 負數向下取整不同於朝零去掉小數。-3.2 的結果為 -4；只有在正數時，向下取整才會看起來像直接保留整數部分。判斷時先找相鄰兩個整數，再選數線左邊的一個；這個方法在正數與負數都適用，不需為每種符號背不同口訣。

- 原值已是整數時不變。-3 不會變成 -4，12 不會變成 11，零仍是零；不要把「向下」理解成每次都減一。

- 本函數的結果表示數學取整，不會判斷數據是否合理。若拿來處理數量、時間或金額，先確認原單位及負值的業務意思，再解讀答案。

## 常見錯誤

1. 主題得到 -3，與預期的 -4 不同。

原因：可能只改了小數顯示格式，或手動把 B2 的小數刪掉。　處理：把 B2 恢復為 -3.2，選 E2，在公式列重新輸入 =INT(B2)，按 Enter 核對。如果先前已覆蓋原值，單改公式無法找回原來的小數，必須依原表補回。

2. 輸入時提示參數太多。

原因：誤以為必須加第二個參數控制位數。　處理：INT 只需要一個參數；將公式修正為 =INT(B2)，移除逗號後多餘的內容。

3. E2 顯示 #VALUE!。

原因：B2 可能輸入了「負3.2」或包含單位，無法作為本例數字。　處理：將 B2 重打為半形 -3.2，確認公式沒有引用 A2 的文字標籤，再重新計算。

## 自己試一次

先遮住解答，試著自己輸入公式並預測結果。每題都從上方的原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　略小於零

先恢復原始 A1:B8；E1 輸入「負小數取整」，在 E2 計算 B6。

參考公式：

```excel
=INT(B6)
```

正確結果：-1

解答 1　B6 為 -0.2，介於 -1 與 0 之間，0 比它大，不能作為向下取整答案。

解答 2　選擇 -1；這個例子能檢查自己是否誤用了朝零刪小數的想法。

### 練習 2　略大於零

先恢復原始 A1:B8；E1 輸入「正小數取整」，在 E2 計算 B7。

參考公式：

```excel
=INT(B7)
```

正確結果：0

解答 1　B7 為 0.9，介於 0 與 1 之間，向下取最接近的整數是 0。

解答 2　即使小數部分很接近 1，也不會進到 1；本題不採用四捨五入規則。

### 練習 3　更換負數

先恢復原始 A1:B8，只把 B2 改為 -8.01；E1 輸入「新負數取整」，在 E2 使用原公式。

參考公式：

```excel
=INT(B2)
```

正確結果：-9

解答 1　-8.01 比 -8 更小，位於 -9 與 -8 之間。

解答 2　向下取整要選 -9；只有原值恰為 -8 時，結果才會保持 -8。
