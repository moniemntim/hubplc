LARGE 回傳排序後第 k 個「觀測值」，重複數值各占一個位置。它很適合設定峰值檢查門檻，但不等於第 k 個不同的數值；兩種規則要先在報表上說清楚。

## 主案例：找出壓力曲線的第二高峰

試車紀錄的壓力峰值如下。工程師要以第二高的觀測值做複核門檻，並保留同值峰的意義。

| 儲存格 | 內容                   |
| ------ | ---------------------- |
| A1:B1  | 時段、壓力（bar）      |
| A2:B2  | 08:00、94              |
| A3:B3  | 09:00、88              |
| A4:B4  | 10:00、94              |
| A5:B5  | 11:00、76              |
| A6:B6  | 12:00、90              |
| D1     | k                      |
| D2     | 2                      |
| E1     | 第 k 大壓力            |
| E2     | `=LARGE($B$2:$B$6,D2)` |

E2 為 **94**。由大到小排是 94、94、90、88、76；第二個觀測值仍是 94，因為兩個 94 各占一個位置。若問題其實是「第二高的不同壓力」，答案才是 90，必須另建去除重複值的流程，不能把 LARGE 的 94 說成公式錯誤。

### 先限制 k 的範圍

在 F1 輸入「安全結果」，F2 輸入：

```excel
=IF(NOT(ISNUMBER(D2)),"k 必須為正整數",IF(OR(D2<>INT(D2),D2<1,D2>COUNT($B$2:$B$6)),"k 超出範圍",LARGE($B$2:$B$6,D2)))
```

資料共有 5 個數字，因此 D2 只能填 1 到 5 的整數。填文字時會顯示「k 必須為正整數」；填 0、2.5 或 6 時會顯示「k 超出範圍」，不要直接把錯誤值當成沒有峰值。若 B 欄夾有文字、空白或量測錯誤，先清理並重新確認 COUNT 的筆數。

## 操作與結果解讀

1. 在 D2 輸入 2，E2 輸入 LARGE 公式。k 是位置，不是壓力值，也不是 Excel 欄號。
2. 手動排序數值核對 E2；兩筆 94 都存在時，第一、第二大均為 94。
3. 要追查峰值發生的時段，篩選 B 欄等於 94，會得到 08:00 與 10:00。LARGE 本身不會回傳時段。

## 常見失敗與修正

- **把第二大期待成 90**：那是第二個不同值的定義，不是 LARGE 的第 2 個觀測值。
- **k 大於數字筆數**：先用 COUNT 檢查可用筆數，並以 F2 這種防呆訊息阻止錯誤外流。
- **對文字格式的壓力數字直接排序**：先轉為實際數值；否則 COUNT、LARGE 與人工排序可能使用不同資料。

## 獨立練習

將 D2 改為 3，E2 應為 **90**；改為 5，應為 **76**；改為 6 或 2.5，F2 應顯示「k 超出範圍」；改為文字 `第二`，F2 應顯示「k 必須為正整數」。請比較第 2 與第 3 大，說明並列峰值如何占據排序位置。
