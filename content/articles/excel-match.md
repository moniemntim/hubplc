本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會在單欄清單中找出指定項目的相對位置，並明確使用零要求完全符合。完成後能分辨位置數字、工作表列號與項目本身，知道重複項目會回傳第一個位置，找不到時也能理解錯誤的原因，而不把它誤當成零。

## 適用版本

適用 Microsoft 365 與 Excel 2016 至 2024

## 用途

- 在固定順序的處理清單中，查某個品項排在第幾筆，快速確認位置後再回原表查看相關資料。結果代表目前清單順序，不是永久識別碼。如果使用者在原表插入或移動紀錄，這個相對位置可能變動，應重新看計算結果，而不是把先前的數字當成固定資料。

- 檢查輸入的品項是否存在於一份標準清單；有找到可取得位置，找不到則進一步核對拼字或資料來源，避免直接假設不存在。

## 先準備範例資料

開啟空白活頁簿，依下表輸入。英文字母是欄，數字是列；例如 B2 就是 B 欄第 2 列。標題從 A1 開始，結果另外放在 E2。

| 列 | A |
| --- | --- |
| 1 | 品項 |
| 2 | 筆 |
| 3 | 橡皮擦 |
| 4 | 尺 |
| 5 | 筆記本 |
| 6 | 膠帶 |
| 7 | 筆 |
| 8 | 剪刀 |

- A1 為品項標題，A2:A8 共七筆資料；主題在這七格尋找文字「尺」，不把標題列算進範圍。

- A2 與 A7 都是「筆」，重複是刻意安排；兩個位置分別為 1 和 6，方便觀察完全符合時取第一筆。

- 「尺」在 A4，但從 A2 開始數是第三個項目。因此答案 3 不代表工作表第 3 列，也不是庫存數量。你可以把答案讀成「尺位於這段清單的第三個位置」，這句話比單說第三列更清楚，能避免把範圍起點忘掉。

- E1 為「尺的位置」，E2 放公式。清單沒有按照文字順序排序，使用第三參數 0 時不需要先排序。

## 輸入這個公式

```excel
=MATCH("尺",A2:A8,0)
```

輸入位置：E2　　正確結果：3

建議順序：先照做並核對畫面，再看公式拆解，最後完成延伸用法與練習。所有練習各自從這一頁的原始資料開始。

## 照著做並核對畫面

名稱方塊在公式列左側，會顯示 A1 或 E2 等位置；公式列則是 fx 右邊顯示公式的長欄位。下列步驟都在工作表內操作。

1. 在空白工作表 A1:A8 輸入原始清單，確認 A2、A7 都為筆，A4 為尺，文字前後沒有多餘空格。

2. 選取 A2:A8，從上往下數七筆，核對尺是第三筆；保持原始順序，不要為了輸入公式先排序。

3. 選 E1 輸入「尺的位置」，再選 E2，設為通用格式或數字，準備接收位置編號。

4. 在 E2 輸入 =MATCH("尺",A2:A8,0)，按 Enter。文字尺用半形雙引號，末尾的數字 0 必須保留。

5. 確認 E2 顯示 3，再選 E2 看公式列；回原表數 A2、A3、A4，確認第三個位置確實是尺。

## 對照畫面確認結果

- A4 中的尺與 E2 的 3 要一起看：工作表第 4 列，等於所選範圍的第 3 筆。

- 公式末尾是 ,0)，表示本課使用完全符合，不依賴近似比較。如果第三參數不見了，先修正公式再判讀答案；畫面偶然出現正確數字，也不能證明查找設定符合本題。

- 清單裡有兩個筆，但主題找的是尺；重複筆只在延伸題用來觀察第一個符合位置。

## 語法與引數

```excel
=MATCH(lookup_value,lookup_array,[match_type])
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

lookup_value　必要。要找的內容，可用文字、數字或儲存格參照。本例 "尺" 是文字；引號只是公式標記，不是名稱的一部分。

lookup_array　必要。搜尋用的單列或單欄範圍。本例 A2:A8 是一欄七格，答案以此範圍的第一格為位置 1。

[match_type]　選填但本課必填 0，找第一個完全符合值且不要求排序。省略等同 1，採近似規則且需遞增排序；-1 採另一種近似規則且需遞減排序，因此不能隨意省略。

## 把主公式逐段拆開

=　開頭等號讓 Excel 把後面的內容視為計算公式。

MATCH　本課唯一使用的函數名稱，拼字須完整，不含空格。

( )　成對半形括號包住所有參數；最後一定要有右括號。

"尺"　要尋找的文字，使用半形雙引號包住，不要把引號也打入來源格。

A2:A8　冒號含起點與終點，回傳的位置以 A2 為 1 往下數。

0　數字零指定完全符合；它不是找不到時的預設答案，也不是要求傳回第零筆。

,　半形逗號分開不同參數；引號裡的符號則是文字本身。

使用半形 = ( ) , : 及雙引號；文字使用直式雙引號 " "。部分地區設定以分號分隔引數，請依 Excel 的輸入提示調整。

## Excel 如何得到這個答案

1. 先以 A2 為位置 1，檢查內容筆，與尺不同，繼續往下。

2. 位置 2 是 A3 的橡皮擦，也不符合；位置 3 是 A4 的尺，第一次找到相同內容。

3. 停止並回傳相對位置 3。答案沒有帶回尺這個文字，也沒有改寫原清單。若要人工核對位置，就從 A2 重新數一次，而不是直接看工作表左側列號。這個動作也能發現是否誤把標題納入。

## 資料型態與邊界情況

- 完全符合時若同名出現多次，回傳第一個符合位置；這不代表清單只有一筆，也不會列出所有符合項目。因此用來檢查重複名單時，還要回來源查看後面是否有另一筆；單一位置結果沒有提供整段範圍的符合次數。

- 找不到會顯示 #N/A，不是 0。應檢查要找的字與來源，並留意前後空格；文字與數字型別不同也可能導致未符合。

- 文字查找不區分英文字母大小寫；即使使用 0，文字中的 * 與 ? 仍有萬用字元意義。本課使用一般中文品項，沒有使用這些符號。

## 同一個函數的延伸用法

以下例子彼此獨立。每做一題前，先還原第一頁的原始資料，再執行該題設定；不要沿用上一題的修改。

### 用法 1　查找重複名稱

先恢復原始 A1:A8，E1 改為「筆的位置」，在 E2 輸入下式。

```excel
=MATCH("筆",A2:A8,0)
```

結果：1

A2 與 A7 都是筆，分別位於範圍內位置 1、6。

從上往下第一個符合的是 A2，所以回傳 1，不回傳 6 或筆數 2。

### 用法 2　查找最後一筆

先恢復原始 A1:A8，E1 改為「剪刀的位置」，在 E2 輸入下式。

```excel
=MATCH("剪刀",A2:A8,0)
```

結果：7

剪刀在 A8，是 A2:A8 範圍最後一格。

範圍有七筆，最後位置為 7，不能直接用工作表列號 8 作答案。

## 常見錯誤

1. 找到的答案不可靠或出現非預期位置

原因：第三參數被省略，預設近似比對不適合本課未排序清單。　處理：在公式最後明確補上 ,0，重新按 Enter；不要為了得到答案任意排序清單。

2. 明明看得到名稱卻顯示 #N/A

原因：名稱可能有多餘空格、不同字形，或引用範圍漏掉該格。　處理：核對原格與查找文字逐字一致，並確認範圍完整是 A2:A8。

3. 答案是 4，不是 3

原因：範圍可能從 A1 開始，把標題也算成位置 1。　處理：把範圍恢復為 A2:A8，再由 A2 重新數位置。

## 自己練習與完整解答

先遮住解答，試著自己輸入公式並預測結果。每題都從第一頁原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　查找膠帶

先恢復原始 A1:A8，E1 改為「膠帶的位置」，在 E2 查找膠帶並要求完全符合。

答案公式：

```excel
=MATCH("膠帶",A2:A8,0)
```

正確結果：5

解答 1　膠帶在 A6，從 A2 數起是第五筆。

解答 2　第三參數填 0，回傳 5。

### 練習 2　查找未列出的名稱

先恢復原始 A1:A8，E1 改為「訂書機的位置」，在 E2 查找訂書機。

答案公式：

```excel
=MATCH("訂書機",A2:A8,0)
```

正確結果：#N/A

解答 1　逐格檢查七筆清單，沒有訂書機。

解答 2　完全符合找不到時回傳 #N/A；這個錯誤是本題預期結果，不要填成 0。

### 練習 3　更新第一筆名稱

先恢復原始 A1:A8，只把 A2 改為「原子筆」；E1 改為「筆的位置」，在 E2 查找筆。

答案公式：

```excel
=MATCH("筆",A2:A8,0)
```

正確結果：6

解答 1　A2 已不再是完全相同的筆，後面的 A7 仍為筆。

解答 2　A7 從 A2 數起是第六筆，所以回傳 6。
