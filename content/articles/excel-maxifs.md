MAXIFS 適合回答「指定班別、指定設備類型的最高值是多少？」。它只回傳數值；若最高值有並列，還要回到原始紀錄找出所有同值列，不能把結果誤當成唯一的一筆。

## 主案例：交班前找加熱區的溫度峰值

日班工程師要確認加熱區是否曾超過 70°C。把班別與區域當成條件，溫度當成要比較的數值。請在空白工作表輸入下列資料：

| 儲存格 | 內容                                                     |
| ------ | -------------------------------------------------------- |
| A1:C1  | 班別、設備區、最高溫度（°C）                             |
| A2:C2  | 日班、加熱區、68                                         |
| A3:C3  | 夜班、加熱區、71                                         |
| A4:C4  | 日班、冷卻區、0                                          |
| A5:C5  | 日班、加熱區、71                                         |
| A6:C6  | 日班、加熱區、69                                         |
| A7:C7  | 日班、加熱區、71                                         |
| E1     | 日班加熱區峰值                                           |
| E2     | `=MAXIFS($C$2:$C$7,$A$2:$A$7,"日班",$B$2:$B$7,"加熱區")` |

E2 的結果是 **71**。符合兩個條件的列是第 2、5、6、7 列；其中第 5 與第 7 列都為 71，所以這是「峰值為 71°C」，不是「只有一筆峰值」。本表沒有時間或機台欄位；若要追查來源，原始紀錄必須另外保留這些欄位，不能由本表推定。

### 不要把「無資料」當成 0°C

在 F1 輸入「停機班次筆數」，F2 輸入：

```excel
=COUNTIFS($A$2:$A$7,"停機",$B$2:$B$7,"加熱區")
```

F2 結果為 **0**，表示沒有符合紀錄。相對地，C4 的 **0** 是冷卻區一筆真實量測值；它不會影響日班加熱區的 MAXIFS，卻不能與「沒有符合列」混為一談。報表需要顯示峰值前，先判斷 COUNTIFS 是否為 0：為 0 時標示「無量測資料」，不要標示「0°C」。

## 操作與檢查順序

1. 將 E2 公式貼上或輸入，確認 `max_range` 是 C2:C7，兩個條件範圍分別是 A2:A7、B2:B7，三個範圍的起訖列一致。
2. 先用篩選保留「日班」與「加熱區」，手動比較 68、71、69、71；結果應為 71。
3. 若交班規則是「峰值不得超過 70°C」，可用 E2 判定需追查；本表只指出值與列號，時間、機台與責任歸屬必須回到另有保存那些欄位的原始紀錄確認。

## 常見失敗與修正

- **結果把夜班的 71 算進來**：通常是漏掉班別條件，或把 B 欄當成 A 欄。逐一確認每個條件範圍與條件文字。
- **結果是 0 就判定溫度為 0**：先用 COUNTIFS 確認是否有符合列；0 可能是無資料的訊號，不是可比較的量測值。
- **要找第二高「不同溫度」卻使用 MAXIFS**：MAXIFS 只找最高值。先建立符合條件的資料清單，再依明確規則處理並列或不同值。

## 獨立練習

以下兩題彼此獨立，資料 A2:C7 不變：

1. 將 E2 改為 `=MAXIFS($C$2:$C$7,$A$2:$A$7,"夜班",$B$2:$B$7,"加熱區")`，應回傳 **71**；F2 改為 `=COUNTIFS($A$2:$A$7,"夜班",$B$2:$B$7,"加熱區")`，應為 **1**。
2. 還原班別為日班，將 E2 改為 `=MAXIFS($C$2:$C$7,$A$2:$A$7,"日班",$B$2:$B$7,"冷卻區")`，應回傳 **0**；F2 改為 `=COUNTIFS($A$2:$A$7,"日班",$B$2:$B$7,"冷卻區")`，應為 **1**。

第二題的 0 代表有一筆真實的 0°C 量測，不是無資料。

## 函數語法與參考資料

```excel
=MAXIFS(max_range,criteria_range1,criteria1,[criteria_range2,criteria2],...)
```

`max_range` 是要比較的數值；每一組 `criteria_range` 與 `criteria` 用來保留符合的列。請以 [Microsoft MAXIFS 函數說明](https://support.microsoft.com/zh-tw/excel/functions/maxifs-function) 為準。
