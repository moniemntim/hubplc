MINIFS 適合從已定義為有效的紀錄中找最短時間。本課不把故障碼 0、尚未完成的空白列當成優秀的循環時間；資料狀態要先寫清楚，公式才有可解釋的意義。

## 主案例：找出最短的有效校正循環

維修主管要設定校正站的正常循環基準。故障中止會記為 0，尚未結束的作業沒有分鐘數，兩者都不應參與比較。

| 儲存格 | 內容                                                 |
| ------ | ---------------------------------------------------- |
| A1:C1  | 工單、狀態、循環分鐘                                 |
| A2:C2  | 清潔、完成、18                                       |
| A3:C3  | 校正、完成、9                                        |
| A4:C4  | 夾具異常、故障、0                                    |
| A5:C5  | 等待材料、未完成、（留白）                           |
| A6:C6  | 點檢、完成、12                                       |
| A7:C7  | 校正複驗、完成、9                                    |
| E1     | 最短有效循環                                         |
| E2     | `=MINIFS($C$2:$C$7,$B$2:$B$7,"完成",$C$2:$C$7,">0")` |

E2 的結果是 **9**。公式要求狀態為「完成」且分鐘大於 0，因此第 4 列故障碼與第 5 列空白都不會進入計算。第 3 與第 7 列並列 9 分鐘，這表示目前最短紀錄有兩筆；它不是自動認定的標準工時，仍要確認兩筆是否使用相同工法與批次。

### 先查資料品質，再用最小值做決策

在 F1 輸入「有效筆數」，F2 輸入：

```excel
=COUNTIFS($B$2:$B$7,"完成",$C$2:$C$7,">0")
```

F2 應為 **4**。若為 0，E2 的數值不應直接拿去做排程；先查是所有工單尚未完成、狀態拼字不同，還是分鐘欄被輸入為文字。MINIFS 的結果回答的是「目前符合規則的最小值」，不是「資料一定完整」。

## 操作與結果解讀

1. 在 C 欄只輸入實際分鐘；0 必須有明確的「故障」意義，不能同時代表尚未量測。
2. 在 E2 輸入公式，確認最小範圍 C2:C7 與兩個條件範圍都涵蓋同一批資料列。
3. 手動圈出完成且大於 0 的 18、9、12、9，最小值應為 9。
4. 要以 9 分鐘當改善目標前，先開啟兩筆校正紀錄；若其中一筆使用了不同設備，應另訂比較條件，而不是刪掉資料。

## 常見失敗與修正

- **結果是 0 分鐘**：通常沒有排除故障碼。加入狀態條件及 `">0"`，並確認 0 的業務定義。
- **空白列被當成已完成**：狀態欄和時間欄必須同時檢查；空白不是可比較的短工時。
- **只有一筆最小值就當作常態**：MINIFS 不會告訴你分布或樣本數。先看 F2 的有效筆數與原始工單。

## 獨立練習

將 B6 的狀態改為「故障」，E2 仍為 **9**、F2 變為 **3**。下一題先把 B6 還原為「完成」，再把 C3 與 C7 的分鐘都改為 11，E2 應為 **11**、F2 為 **4**；這代表最短的有效校正循環已改變，不代表故障資料被修正。
