本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會求兩數相除的餘數，分清剩餘數量與完整組數，並知道參數的先後次序。本課先用二十三張貼紙每五張一組的例子，再觀察負數及零除數；完成後，你能手算主答案，說明非零餘數的正負跟隨除數，並辨認不能除以零的錯誤。

## 什麼時候會用到

- 分裝貼紙、卡片或零件時，計算完成若干整組後還剩多少件，協助安排補件或散裝；本函數回答剩餘數，不直接回答可分幾組。報告時最好把餘數單位寫清楚，例如「剩三張」，不要只寫「三」，以免被誤讀成三組或三箱。

- 檢查一批數量是否剛好整除，例如二十張每五張一組時餘數為零。零餘數表示沒有剩餘，不能解讀為沒有任何物品或沒有完成整組。

## 適用版本

- Microsoft 官方適用版本列出 Microsoft 365、Excel 2024、Excel 2021、Excel 2019 與 Excel 2016；本課用一般儲存格公式即可完成。

- 本課使用半形逗號分隔參數，輸入後直接按 Enter。若系統地區設定要求分號，請依當地 Excel 的參數提示調整分隔符號。

## 先準備範例資料

開啟空白活頁簿，依下表輸入對應儲存格。表中「（空白）」代表儲存格留空，請勿輸入括號內的文字。

| 列 | A | B | C |
| --- | --- | --- | --- |
| 1 | 項目 | 數量 | 每組數量 |
| 2 | 貼紙甲 | 23 | 5 |
| 3 | 貼紙乙 | 20 | 5 |
| 4 | 正數測試 | 3 | 2 |
| 5 | 負被除數 | -3 | 2 |
| 6 | 負除數 | 3 | -2 |
| 7 | 兩者皆負 | -3 | -2 |
| 8 | 零數量 | 0 | 5 |

- 原始表位於 A1:C8。A 欄是名稱，B 欄是被分配的數量，C 欄是每組數量；主公式使用 B2 的 23 與 C2 的 5，位置順序不可互換。

- B3 的 20 配 C3 的 5，示範剛好分完；B8 的 0 配 C8 的 5，示範零數量。這兩種情形結果都為零，但意義不同。

- 第 5 至 7 列含負數，只用來理解運算規則，不當成真實貼紙數量。B5 為 -3、C5 為 2；B6 為 3、C6 為 -2；B7、C7 皆為負數。

- B2:C8 與 E2 可設為數值、零位小數。C 欄原始資料全部非零；後面的零除數練習會要求你明確修改，完成後需恢復原表。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=MOD(B2,C2)
```

輸入位置：E2　　正確結果：3

## 語法與引數

```excel
=MOD(number, divisor)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

number　必要參數，被除數，也就是要被分成整組的數字。本課填 B2，其值為 23；可為正數、負數或零。

divisor　必要參數，除數。本課填 C2，其值為 5；不得為零。數學上可以為負，但實務的每組數量通常應是正數。檢查參數時先問「每幾個算一組」，能幫助記住它的位置在逗號後方；若單位不同，應先統一單位再計算。

公式使用半形標點；部分地區設定以分號分隔引數，請依 Excel 的提示調整。

## 照著做並核對畫面

1. 在空白工作表點 A1，依表建立 A1:C8。先核對 B2 是 23、C2 是 5，再逐格檢查第 5 至 7 列的負號。
2. 選取 B2:C8，設為數值、零位小數。A 欄只作標籤，不要將「張」輸入數值格；需要單位時放在標題或說明。
3. 選 E1，輸入「剩餘未滿一組數量」，再選 E2。此處在原始三欄之外，可避免覆蓋數量與每組數量。
4. 點 E2 的公式列，輸入 =MOD(B2,C2)，確認逗號左側是被除數、右側是除數，括號成對後按 Enter。
5. 重新選 E2，確認結果為 3、公式列為 =MOD(B2,C2)。用四組各五張共二十張，二十三減二十剩三張，核對答案。

## 結果解讀

1. 先讀 B2 的 23 與 C2 的 5，將問題說成二十三除以五的餘數，確認不是五除以二十三。

2. 五張一組可取四個完整組，共使用 5 乘 4 等於 20 張；再多一組就需要 25 張，超過現有數量。

3. 用 23 減去 20，得到餘數 3。可以用 23 等於 5 乘 4 加 3 驗算，且 3 小於正除數 5。

4. E2 回傳 3；完整組數 4 是手算時用來理解的中間量，不是本函數的輸出。若有人問能分幾組，這個儲存格的三並沒有回答該問題；閱讀結果標題與公式名稱同樣重要。

- 當餘數不是零時，正負號跟隨除數。例如 -3 除以 2 的餘數是 1，而 3 除以 -2 的餘數是 -1；不要沿用只看被除數負號的直覺。除數為正時，餘數會介於零與除數之間，且小於除數；本課整數分組可用這項特性做快速合理性檢查。

- 除數為零會回傳 #DIV/0!，不是零餘數。應修正來源的分組數量或查明資料問題，不能將這個錯誤當成剛好分完。

- 本課以整數示範最容易驗算。若使用很細的小數，電腦儲存精度可能使結果出現微小差異；應先確定單位與精度需求再擴充。

## 常見錯誤

1. E2 得到 5 而非 3。

原因：可能把 B2、C2 的順序交換，計算成五除以二十三。　處理：在公式列恢復 =MOD(B2,C2)，再確認 B2 是 23、C2 是 5。

2. E2 顯示 #DIV/0!。

原因：除數為 0，或引用到作為零處理的空白除數格。　處理：選 C2 檢查內容，恢復數字 5；實務資料若未知每組數量，先查明，不能隨便補一個值。將結果格改成零不能修正來源錯誤，反而會讓報表看起來像已經整除，掩蓋問題。

3. 負數測試的正負號與預期不同。

原因：把餘數符號誤認為永遠跟隨被除數。　處理：先看逗號右側除數的正負號，再用「被除數＝除數乘整數＋餘數」核對。

## 自己試一次

先遮住解答，試著自己輸入公式並預測結果。每題都從上方的原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　更換每組數量

先恢復原始 A1:C8；只把 C2 改成 4，E1 保留原標題，在 E2 使用原公式。

參考公式：

```excel
=MOD(B2,C2)
```

正確結果：3

解答 1　23 可以分成五組各四張，共使用 20 張。

解答 2　23 減 20 等於 3，因此餘數仍是 3，但完整組數已由四組變為五組。

### 練習 2　負的除數

先恢復原始 A1:C8；E1 輸入「負除數餘數」，在 E2 計算 B6 除以 C6。

參考公式：

```excel
=MOD(B6,C6)
```

正確結果：-1

解答 1　B6 是 3，C6 是 -2；餘數若非零，應與除數同為負。

解答 2　3 等於 -2 乘 -2 加 -1，所以餘數是 -1。

### 練習 3　辨認零除數

先恢復原始 A1:C8；只把 C2 改成 0，E1 輸入「零除數測試」，在 E2 使用原公式。

參考公式：

```excel
=MOD(B2,C2)
```

正確結果：#DIV/0!

解答 1　本題將除數設為零，除法無法成立，所以不會得到數字餘數。

解答 2　應看見 #DIV/0!。完成後把 C2 恢復為 5，主公式即可重新得到 3。
