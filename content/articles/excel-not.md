本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會先判斷一個條件的真假，再用 NOT 反轉結果，並讀懂 TRUE 與 FALSE。本課以案件是否不是已完成為例，練習文字比較與引號；完成後，你能區分邏輯結果與原始狀態，知道 TRUE 並不自動代表成功或應繼續處理。

## 適用版本

適用 Microsoft 365 與 Excel 2016 至 2024

## 用途

- 案件清單需要標示哪些資料不等於指定狀態時，可將「是否已完成」的判斷反轉，得到「是否不是已完成」的真假結果，方便人工檢查例外。

- 已經有一個明確條件時，例如數值是否大於門檻，可反轉成不是大於門檻。先把原條件說清楚，再解讀結果，能避免雙重否定造成誤會。

## 先準備範例資料

開啟空白活頁簿，依下表輸入。英文字母是欄，數字是列；例如 B2 就是 B 欄第 2 列。標題從 A1 開始，結果另外放在 E2。

| 列 | A | B |
| --- | --- | --- |
| 1 | 案件 | 處理狀態 |
| 2 | 案件甲 | 待處理 |
| 3 | 案件乙 | 已完成 |
| 4 | 案件丙 | 處理中 |
| 5 | 案件丁 | 已完成 |
| 6 | 案件戊 | 待處理 |
| 7 | 案件己 | 已取消 |
| 8 | 案件庚 | 已完成 |

- 在 A1:B8 輸入案件與狀態。主題用 B2 的「待處理」，B3、B5、B8 是「已完成」，B4 是「處理中」，B7 是「已取消」。

- B 欄輸入狀態本身，不要加任何引號，也不要在前後按空白鍵。公式內用來比較的固定文字才要用半形雙引號包住。

- 本題 TRUE 與 FALSE 是邏輯值，分別表示括號內條件經反轉後成立與不成立。它們不是要事先打進 E2 的文字答案，也不需要加引號。

- 「已取消」也不等於「已完成」，因此若對 B7 做相同測試會得到 TRUE。這不代表已取消案件仍需處理，業務含義不能只靠函數自行決定。

## 輸入這個公式

```excel
=NOT(B2="已完成")
```

輸入位置：E2　　正確結果：TRUE

建議順序：先照做並核對畫面，再看公式拆解，最後完成延伸用法與練習。所有練習各自從這一頁的原始資料開始。

## 照著做並核對畫面

名稱方塊在公式列左側，會顯示 A1 或 E2 等位置；公式列則是 fx 右邊顯示公式的長欄位。下列步驟都在工作表內操作。

1. 開啟空白工作表，選 A1，建立 A1:B8。選 B2 在公式列確認「待處理」三字沒有前後空格，再核對 B3 的「已完成」。

2. 在 E1 輸入「是否不是已完成」，把問題寫完整。這個標題能幫你記住答案在回答否定條件，不是直接回答案件是否完成。

3. 選 E2，使用通用格式。點公式列，先輸入等號、NOT 與左括號，再輸入 B2="已完成"，文字用半形雙引號。

4. 補上右括號，確認完整公式為 =NOT(B2="已完成")，只有一個比較條件、沒有逗號，再按 Enter。

5. 重新選 E2，應顯示 TRUE，公式列保留原式。先說「待處理等於已完成是假」，再說「反轉後為真」，確認自己理解結果。

## 對照畫面確認結果

- B2 是「待處理」，E1 問的是「是否不是已完成」，因此 E2 的 TRUE 和題意一致，並沒有把案件變成完成。

- 公式列開頭的等號啟動公式，括號內的等號則做相等比較。兩個等號位置與用途不同，都不能省略。

- 畫面顯示 TRUE 是一般邏輯輸出，並非錯誤訊息。如果看到整串公式，應先檢查儲存格格式與公式輸入方式。

## 語法與引數

```excel
=NOT(logical)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

logical　唯一且必要的參數，必須能判斷為 TRUE 或 FALSE 的值或運算式。本課填 B2="已完成"，先比較狀態，再由 NOT 反轉結果；不能直接用無法判斷真假的一般狀態文字代替。若直接使用邏輯常數 TRUE 或 FALSE，不要加雙引號；引號會把內容標示為文字，容易混淆資料類型與題意。

## 把主公式逐段拆開

=　最前面等號告訴 Excel 開始計算公式。

NOT　把 TRUE 反轉成 FALSE，把 FALSE 反轉成 TRUE。

B2　讀取第一筆案件的狀態文字，不是讀案件編號 A2。

="已完成"　括號內等號是相等判斷；半形雙引號包住固定文字，表示與「已完成」比較。

( )　包住唯一的邏輯條件。本式沒有多個參數，所以不需逗號。

使用半形 = ( ) , : 及雙引號；文字使用直式雙引號 " "。部分地區設定以分號分隔引數，請依 Excel 的輸入提示調整。

## Excel 如何得到這個答案

1. 讀取 B2 的「待處理」，並與公式中的固定文字「已完成」做比較；來源格中的文字本身沒有引號。

2. 兩個狀態不同，B2="已完成" 這個比較條件得到 FALSE。到這一步還只是原條件的答案。

3. NOT 將 FALSE 反轉為 TRUE，所以 E2 顯示 TRUE，意思是這筆案件的狀態不是已完成。

4. 原始 B2 仍為待處理。函數只產生邏輯值，不會替你更改案件狀態，也不會自動發送通知或執行工作。

## 資料型態與邊界情況

- TRUE 只表示目前問的條件成立。若問題改成「是否已取消」或其他否定句，真假結果的業務意義也會改變，不能把 TRUE 一律翻成合格。

- 只接受一個邏輯參數。本課先使用單一相等判斷練習；不要在括號內用逗號羅列多個獨立條件，否則不符合本函數語法。先在紙上寫出原條件與反轉後問題，確認二者互為否定，再開始輸入，通常比盯著英文真假值猜測更容易。

- 文字拼字與空格都應先統一。狀態多一個尾端空格可能導致相等比較不成立，得到與肉眼預期不同的結果；請先檢查原資料。

## 同一個函數的延伸用法

以下例子彼此獨立。每做一題前，先還原第一頁的原始資料，再執行該題設定；不要沿用上一題的修改。

### 用法 1　已完成案件

先恢復原始 A1:B8；E1 保留「是否不是已完成」，在 E2 改測 B3。

```excel
=NOT(B3="已完成")
```

結果：FALSE

B3 的已完成與比較文字相同，原條件得到 TRUE。

NOT 把 TRUE 反轉成 FALSE，表示「不是已完成」這個說法不成立。

### 用法 2　改問是否不是待處理

先恢復原始 A1:B8；E1 改為「是否不是待處理」，在 E2 輸入下式。

```excel
=NOT(B2="待處理")
```

結果：FALSE

B2 正是待處理，因此括號內相等判斷為 TRUE。

反轉後是 FALSE；改比較文字時也要改 E1 問題，避免答案對了卻被錯誤解讀。

## 常見錯誤

1. 看見 TRUE 就以為案件已完成。

原因：忽略 E1 的「不是」，把否定條件當成原始條件。　處理：先完整讀 E1，再依序讀括號內比較與反轉。本例 TRUE 應解讀為狀態不是已完成。

2. E2 顯示 #VALUE!。

原因：可能直接將「待處理」這類一般文字當作邏輯參數。　處理：將公式恢復為 =NOT(B2="已完成")，讓文字先經相等比較產生真假值。

3. 輸入時出現公式錯誤提示。

原因：雙引號或括號用了全形，或文字引號缺一邊。　處理：切換半形英數重新輸入公式，確認「已完成」前後都是半形雙引號，括號只有一對。

## 自己練習與完整解答

先遮住解答，試著自己輸入公式並預測結果。每題都從第一頁原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　處理中案件

先恢復原始 A1:B8；E1 保留原問題，在 E2 判斷 B4 是否不是已完成。

答案公式：

```excel
=NOT(B4="已完成")
```

正確結果：TRUE

解答 1　處理中與已完成不同，括號內相等判斷是 FALSE。

解答 2　NOT 反轉後得到 TRUE；它只表示狀態不同，沒有估計還需要多久。

### 練習 2　已取消案件

先恢復原始 A1:B8；E1 保留原問題，在 E2 判斷 B7 是否不是已完成。

答案公式：

```excel
=NOT(B7="已完成")
```

正確結果：TRUE

解答 1　已取消不等於已完成，原條件為 FALSE，反轉後為 TRUE。

解答 2　結果不能直接當成待辦清單，因為已取消是否還要追蹤，必須另外依業務規則判定。

### 練習 3　更新狀態

先恢復原始 A1:B8，只把 B2 改為「已完成」；E1 保留原問題，在 E2 使用主公式。

答案公式：

```excel
=NOT(B2="已完成")
```

正確結果：FALSE

解答 1　來源更新後，相等判斷由 FALSE 變成 TRUE。

解答 2　NOT 再反轉成 FALSE；公式仍引用 B2，所以不必改公式也會隨資料重算。
