本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

從編號末尾取出固定字數，例如取得訂單編號最後四碼。

## 先準備範例資料

開啟空白活頁簿，依下表把資料輸入對應儲存格。A、B 等是欄名；1、2 等是列號。

| 列 | A |
| --- | --- |
| 1 | 訂單編號 |
| 2 | SO-2026-0827 |
| 3 | SO-2026-0934 |
| 4 | SO-2026-1042 |

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=RIGHT(A2,4)
```

正確結果：0827

語法：

```excel
=RIGHT(text,[num_chars])
```

| 引數 | 代表什麼 |
| --- | --- |
| text | 原始文字或存放文字的儲存格。本課是 A2 的完整訂單編號。 |
| [num_chars] | 選填。從右邊取幾個字元；本課填 4。省略時只取 1 個字元，不能填負數。 |

公式請使用英文名稱及半形標點；若系統以分號分隔引數，請依 Excel 提示改用分號。語法中的方括號表示選填，不必輸入。

## 照著做並核對畫面

1. 在空白工作表的 A1:A4 輸入上表，確認 A2 是 SO-2026-0827。
2. 在 E1 輸入「末四碼」，再點選 E2。
3. 在 E2 輸入 =RIGHT(A2,4)，按 Enter。
4. 重新點選 E2，確認顯示 0827，開頭的 0 也有保留。

公式從 A2 末尾取出 4 個字元，依原本順序傳回「0827」，不會把字元順序倒轉。結果是文字，所以最前面的 0 仍保留。

## 常見錯誤

- 把 4 當成從左數的起點：這裡的 4 是從右側要取出的字元數。
- 以為結果會倒過來排列：RIGHT 只選取右端字元，保留原本順序。
- 原始編號後方多了空格：尾端空格也會占用取出的字元數，應先檢查 A2。

## 自己試一次

把 E2 的公式改為讀取 A3，取出最後四碼，會得到什麼？

參考答案：

```excel
=RIGHT(A3,4)
```

結果：0934。A3 的最後四個字元是 0934；公式傳回文字，開頭的 0 會保留。
