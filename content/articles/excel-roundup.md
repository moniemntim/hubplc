本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會把數值依指定小數位數朝遠離零的方向進位，並能分辨真正改變計算值與只改顯示格式。完成本課後，你能讀懂正、零、負的位數參數，手算正數與負數範例，確認答案方向，再將相同規則用在需要固定精度的資料。

## 什麼時候會用到

- 整理測量或計費資料時，若規則明確要求朝遠離零處理到小數兩位，可保留原數值，另外算出符合規定的處理值，讓檢查者知道調整前後的差異。

- 需要以十位或百位呈現估計數字時，用負的位數參數指定位置。請先確認業務規則真的需要進位，不能只因答案比較好看就自行改變數值。

## 適用版本

- Microsoft 官方適用版本列出 Microsoft 365、Excel 2024、Excel 2021、Excel 2019 與 Excel 2016；本課用一般儲存格公式即可完成。

- 本課使用半形逗號分隔參數，輸入後直接按 Enter。若系統地區設定要求分號，請依當地 Excel 的參數提示調整分隔符號。

## 先準備範例資料

開啟空白活頁簿，依下表輸入對應儲存格。表中「（空白）」代表儲存格留空，請勿輸入括號內的文字。

| 列 | A | B |
| --- | --- | --- |
| 1 | 項目 | 原始數值 |
| 2 | 測試一 | 12.341 |
| 3 | 測試二 | -12.341 |
| 4 | 測試三 | 126 |
| 5 | 測試四 | 12.3 |
| 6 | 測試五 | 0 |
| 7 | 測試六 | 0.001 |
| 8 | 測試七 | -0.001 |

- 本課資料輸入 A1:B8。A 欄是測試名稱，B2:B8 是七個獨立數值；主題只計算 B2，不會自動處理整欄，也不會把七筆資料相加。

- B2 輸入 12.341，B3 輸入 -12.341。負號、小數點都用半形，不加貨幣符號、單位或單引號；這一正一負用來觀察方向。

- B4 的 126 用來測試十位，B5 的 12.3 本來就只有一位小數，B6 是數字 0；B7、B8 是接近零的一正一負小數，不能省略小數點後的零。

- B2:B8 可設為數值、小數三位，E2 設為數值、小數兩位。格式補上的尾端零不改變儲存值；請保留 B 欄原始精度，不要為了畫面整齊而重打原數字。

## 輸入這個公式

在 E2 輸入以下公式，按 Enter。

```excel
=ROUNDUP(B2,2)
```

輸入位置：E2　　正確結果：12.35

## 語法與引數

```excel
=ROUNDUP(number, num_digits)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

number　必要參數，指定要進位的數字，可輸入數字或指向數字儲存格。本課用 B2，讓原值修改後結果自動重算；它不是要處理的筆數。

num_digits　必要參數，指定保留位置。2 表示小數點後兩位，0 表示整數，-1 表示十位，-2 表示百位。本課使用整數參數，不需要百分比或文字標籤。

公式使用半形標點；部分地區設定以分號分隔引數，請依 Excel 的提示調整。

## 照著做並核對畫面

1. 新增空白工作表，按一下 A1，依表填入 A1:B8。輸入後選 B2，從公式列確認完整數值及小數點，接著確認 B3 的負號。
2. 選取 B2:B8，開啟儲存格格式並將數值小數位數設為 3；按確定後，在 E1 輸入「進位至小數兩位」，結果區與原始資料分開。
3. 按一下 E2，先將它設為數值、小數位數 2。確認名稱方塊顯示 E2，再點選公式列準備輸入，不要在 B2 上覆蓋原值。
4. 在公式列輸入 =ROUNDUP(B2,2)，確認 B2 與 2 之間是半形逗號，左右括號成對，再按 Enter。第二個 2 表示保留兩位小數。
5. 重新選取 E2，儲存格應顯示 12.35，公式列應顯示 =ROUNDUP(B2,2)。回到 B2 確認原值仍是 12.341，再以手算核對方向。

## 結果解讀

1. 先從 B2 讀出 12.341，確認它是正數。num_digits 為 2，所以此次要處理到百分位，而不是直接取整數。

2. 保留到百分位的候選值是 12.34；後面還有未處理的數字 1，表示原數值並未剛好落在百分位。

3. 因為必須遠離零，百分位由 4 增加成 5，得到 12.35；即使後面的數字小於 5，也要依本規則進位。

4. 把結果寫入 E2，以兩位小數顯示 12.35。B2 仍保有 12.341，因此之後若要換精度，可以直接修改公式第二個參數。

- 負數的「進位」要按遠離零理解。-12.341 處理到兩位是 -12.35；結果在數線上更小，不能把進位誤解成數值一定變大。

- 若原值已符合位置，就保持不變。例如 12.3 保留兩位仍是 12.3，設定兩位格式後可顯示 12.30；不會無條件再加或減 0.01。

- 只按「減少小數位數」會改變顯示方式，並不等同本函數的計算。需要後續引用處理後數字時，應引用 E2，而不是仍含原始精度的 B2。

## 常見錯誤

1. 預期 12.35，卻只看到 12.4。

原因：E2 可能只顯示一位小數，畫面不足以看出完整答案。　處理：選取 E2，把數值小數位數設為 2，再看公式列是否仍引用 B2、位數參數是否為 2。

2. 負數答案方向與預期相反。

原因：把「進位」誤讀成在數線上固定往大或往小移動。　處理：回到零的位置判斷：本函數固定朝遠離零處理。先用 B3 範例手算，再核對負號與公式名稱。

3. E2 顯示 #VALUE!。

原因：來源可能是含單位的文字，或位數參數填成無法轉成數字的文字。　處理：將 B2 恢復為本課純數字，第二個參數填半形整數 2；不要把「兩位」放進公式。

## 自己試一次

先遮住解答，試著自己輸入公式並預測結果。每題都從上方的原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　改為整數

先恢復原始 A1:B8；E1 改為「整數結果」，在 E2 計算 B2，指定零位小數。

參考公式：

```excel
=ROUNDUP(B2,0)
```

正確結果：13

解答 1　B2 是 12.341；參數 0 指定整數，並非結果必須為零。

解答 2　在 12 與 13 之間依遠離零選擇，得到 13。

### 練習 2　原值已符合精度

先恢復原始 A1:B8；在 E1 輸入「已符合精度」，於 E2 處理 B5，保留兩位小數。

參考公式：

```excel
=ROUNDUP(B5,2)
```

正確結果：12.3

解答 1　B5 是 12.3，百分位之後沒有必須處理的非零部分，所以數值不變。

解答 2　E2 設成兩位小數時顯示 12.30；12.30 與 12.3 是相同數值，尾端零只是格式。

### 練習 3　接近零的小數

先恢復原始 A1:B8；在 E1 輸入「微小數值處理」，於 E2 處理 B7，保留兩位小數。

參考公式：

```excel
=ROUNDUP(B7,2)
```

正確結果：0.01

解答 1　B7 是 0.001，位於 0 與 0.01 之間；要保留到百分位。

解答 2　按遠離零方向得到 0.01，E2 的兩位小數格式應顯示 0.01。
