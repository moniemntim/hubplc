ROUNDUP 會把正數朝較大的方向、負數朝較小的方向處理；它不是一律「往上」。採購整包材料時，需求與包裝都必須是正數，才能把它用在「至少要買幾包」的決策。

## 主案例：依整包規格採購樹脂

某工單需要 253 kg 樹脂，供應商只能以 12.5 kg 整包出貨。少買會停線，因此包數必須朝遠離 0 的方向進位。

| 儲存格 | 內容                                                                                 |
| ------ | ------------------------------------------------------------------------------------ |
| A1:B1  | 項目、數值                                                                           |
| A2:B2  | 需求量（kg）、253                                                                    |
| A3:B3  | 每包重量（kg）、12.5                                                                 |
| A4:B4  | 應採購包數、`=IF(OR(COUNT(B2:B3)<>2,B2<=0,B3<=0),"檢查需求與包裝",ROUNDUP(B2/B3,0))` |
| A5:B5  | 實際到料（kg）、`=IF(ISNUMBER(B4),B4*B3,"")`                                         |
| A6:B6  | 餘量（kg）、`=IF(ISNUMBER(B5),B5-B2,"")`                                             |

B4 的結果是 **21** 包：253 ÷ 12.5 = 20.24，不能採購 0.24 包，所以要進到 21。B5 為 **262.5 kg**，B6 為 **9.5 kg**。這個餘量是多買一整包後的可用物料，不能在報價時寫成「浪費」而不先確認是否可留作下一張工單。

### 先擋住不應計算的輸入

若 B2 為 0 或負數，代表沒有有效需求；若 B3 為 0 或負數，代表包裝規格錯誤或單位輸入錯。COUNT 只計數字，因此輸入成文字的 `253 kg` 或 `'253` 也會被擋下；請把數值與單位分開填。上面的 IF 會顯示「檢查需求與包裝」，避免把 `ROUNDUP(-3,0)` 這類數學結果誤用成採購指令。B5、B6 只在 B4 是數字時才計算，避免把防呆文字延伸成錯誤值。需求量與包裝量要使用同一單位，例如都用 kg，不能一欄 kg、另一欄 g。

## 操作與檢查順序

1. 在 B2、B3 輸入正數，B4 貼上完整公式；第二個參數 0 表示結果要是整數包數。
2. 以計算機或手算確認 20.24 進位為 21，再由 B5、B6 檢查是否確實滿足 253 kg。
3. 若採購規則改成可拆包或最小訂購量另有要求，先改寫業務規則；ROUNDUP 不會替你判斷供應商是否允許拆包。

## 常見失敗與修正

- **只把儲存格格式設成 0 位小數**：顯示 20 不等於實際包數變成 20。必須在公式中使用 ROUNDUP。
- **使用 `ROUNDUP(B2/B3,1)`**：結果是 20.3，不是可下單的整包數。整包需求應用 0 位。
- **負數需求仍得到數字**：公式可以計算，但採購意義不成立；保留輸入防呆並回頭確認退料或沖銷流程。

## 獨立練習

把 B2 改為 250，B4 應為 **20**、B6 為 **0**。把 B2 改為 250.1，B4 應為 **21**、B6 為 **12.4**。把 B3 改為 0，B4 必須顯示「檢查需求與包裝」。

## 函數語法與參考資料

```excel
=ROUNDUP(number, num_digits)
```

`num_digits` 為 0 時回傳整數；負數位數可用於十位、百位等位置，但不應未確認規則就套用到訂購量。請以 [Microsoft ROUNDUP 函數說明](https://support.microsoft.com/zh-tw/excel/functions/roundup-function) 為準。
