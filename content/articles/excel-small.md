SMALL 可從一欄數字取第 k 小值，但維修資料常混有故障 0、未完成空白與文字備註。先用輔助欄留下合格的正數時間，再用 SMALL，能讓舊版工作簿也看得出排除規則。

## 主案例：找出第二短的有效循環

下列資料中，故障 0 不是完成時間，未完成列也不能拿來排名。D 欄是可稽核的輔助欄，不需要以新版專屬動態陣列函數才能理解。

| 儲存格 | 內容                                                          |
| ------ | ------------------------------------------------------------- |
| A1:D1  | 站別、狀態、循環分鐘、有效分鐘                                |
| A2:D2  | 線 1、完成、19、`=IF(AND(B2="完成",ISNUMBER(C2),C2>0),C2,"")` |
| A3:D3  | 線 2、故障、0、將 D2 向下填滿                                 |
| A4:D4  | 線 3、完成、12、將 D2 向下填滿                                |
| A5:D5  | 線 4、未完成、（留白）、將 D2 向下填滿                        |
| A6:D6  | 線 5、完成、12、將 D2 向下填滿                                |
| A7:D7  | 線 6、完成、27、將 D2 向下填滿                                |
| F1     | k                                                             |
| F2     | 2                                                             |
| G1     | 第 k 短有效循環                                               |
| G2     | `=SMALL($D$2:$D$7,F2)`                                        |

D 欄有效資料為 19、12、12、27；G2 為 **12**。兩筆 12 分鐘都會占位置，因此第一小與第二小同為 12。這個數字是第二短的有效觀測值，不代表有兩個不同的循環時間。

### 輔助欄讓排除規則可見

在 H1 輸入「安全結果」，H2 輸入：

```excel
=IF(NOT(ISNUMBER(F2)),"k 必須為正整數",IF(OR(F2<>INT(F2),F2<1,F2>COUNT($D$2:$D$7)),"k 超出有效筆數",SMALL($D$2:$D$7,F2)))
```

F2 只能填 1 到 4 的整數。輸入文字時會顯示「k 必須為正整數」；輸入 0、2.5 或 5 時會顯示「k 超出有效筆數」。D 欄的空字串不是 0 分鐘；它表達「這列未被納入」。若將狀態改為完成但 C 欄是文字，例如 `12 分`，ISNUMBER 會使 D 欄留白，提醒先把原始欄位修成數字而不是偷偷截字。

## 操作與檢查順序

1. 先在 D2 輸入 IF/AND/ISNUMBER 公式，再填滿 D2:D7；逐列檢查故障與未完成列是否留白。
2. 在 F2 輸入位置 k，在 G2 用 SMALL 取值。以 12、12、19、27 手動排序核對結果。
3. 若要列出是哪幾個站別達到 12 分鐘，再以 D 欄篩選 12；SMALL 不會提供站別名稱。

## 常見失敗與修正

- **直接對 C 欄用 SMALL**：故障碼 0 會被視為最短時間，造成假象。
- **把空白替換成 0**：未完成不是 0 分鐘。保持空白並以狀態欄說明原因。
- **把第 2 小當成第二個不同值**：兩筆 12 會占第一與第二個位置；不同值的排名需另訂去重規則。

## 獨立練習

將 F2 改為 3，G2 應為 **19**；改為 5 或 2.5，H2 應顯示「k 超出有效筆數」；改為文字 `第二` 時，H2 應顯示「k 必須為正整數」。再把 B3 改為「完成」、C3 改為 8，D3 應為 8，F2=2 時 G2 應仍為 **12**。
