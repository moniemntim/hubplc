本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會把一段名單合併為一個儲存格，自己決定各項之間的分隔符號，以及是否略過真正空白。完成後能檢查名單順序、空格與空白格的差異，並能用範圍參照重新組合不同名單，不需逐個手動複製姓名。

## 適用版本

Microsoft 365 或 Excel 2019 起

## 用途

- 把活動登記表的一欄成員名稱合併成可複製的點名清單，並保留固定頓號，減少人工漏字或少加符號。

- 把同一項目的標籤串成一行摘要。若空欄只是尚未填寫，可選擇略過；若空欄位置有意義，先評估是否要保留分隔位置。不同項目本來就含分隔符號時，要改選不易混淆的符號，否則讀者可能誤以為一個項目被拆成兩個。

## 先準備範例資料

開啟空白活頁簿，依下表輸入。英文字母是欄，數字是列；例如 B2 就是 B 欄第 2 列。標題從 A1 開始，結果另外放在 E2。

| 列 | A |
| --- | --- |
| 1 | 成員 |
| 2 | 小安 |
| 3 | 小柏 |
| 4 | （空白） |
| 5 | 小晴 |
| 6 | 小岳 |
| 7 | （空白） |
| 8 | 小寧 |

- A1 為「成員」，資料範圍 A2:A8 共七格，其中只有五格有名字。A1 不應放進合併範圍。

- A4 與 A7 必須真正空白，請選取各格後按 Delete 清除；不要輸入「空白」、空白鍵或任何標記。

- A2、A3、A5、A6、A8 分別為小安、小柏、小晴、小岳、小寧，皆為虛構名稱，沒有前後空格。名單順序以來源為準；這裡沒有依姓名筆畫排序，也沒有判斷誰先報名。若順序有業務意義，應先確認原表已排妥。

- E1 輸入「合併名單」，E2 是唯一結果格。結果雖含五個名字，仍是一個文字值，不會自動分散成五列。

## 輸入這個公式

```excel
=TEXTJOIN("、",TRUE,A2:A8)
```

輸入位置：E2　　正確結果：小安、小柏、小晴、小岳、小寧

建議順序：先照做並核對畫面，再看公式拆解，最後完成延伸用法與練習。所有練習各自從這一頁的原始資料開始。

## 照著做並核對畫面

名稱方塊在公式列左側，會顯示 A1 或 E2 等位置；公式列則是 fx 右邊顯示公式的長欄位。下列步驟都在工作表內操作。

1. 在空白工作表 A1:A8 輸入原表。A4、A7 跳過不填；若不確定有沒有空白鍵，分別選取這兩格並按 Delete。

2. 選 E1 輸入「合併名單」，再選 E2。拉寬 E 欄或開啟自動換列，預留顯示整串名字的空間。

3. 在 E2 輸入 =TEXTJOIN("、",TRUE,A2:A8)。頓號放在半形雙引號裡，TRUE 不要加引號。

4. 按 Enter，核對 E2 顯示「小安、小柏、小晴、小岳、小寧」，兩個空白位置不應造成連續頓號。

5. 重新選 E2 看公式列，確認範圍是 A2:A8、第二參數為 TRUE；再由上到下對照五個來源名稱是否依原順序出現。

## 對照畫面確認結果

- 左側 A4、A7 沒有內容，但它們仍位於 A2:A8 的範圍之內。

- E2 的五個名字之間有四個頓號，開頭與結尾沒有額外頓號。若看到兩個頓號緊連，先檢查空白處理設定與來源內容，再核對公式，避免直接手改輸出而失去自動更新。

- 公式列中 TRUE 決定略過空白，"、" 決定項目間的分隔文字，兩者作用不同。

## 語法與引數

```excel
=TEXTJOIN(delimiter,ignore_empty,text1,[text2],...)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

delimiter　必要。每兩個合併項目之間插入的分隔文字，本例 "、"。可用 " / " 加上空格，或用 "" 完全不插入分隔文字。

ignore_empty　必要。TRUE 略過空白儲存格；FALSE 保留空白位置，可能出現連續分隔符號。它是邏輯值，不需要雙引號。

text1　必要。第一組要合併的文字、儲存格或範圍。本例使用 A2:A8，按該單欄由上到下讀取。

[text2], ...　選填。可再加入其他文字或範圍，省略就只處理 text1。文字參數總數最多 252 個；一整段範圍算一個參數，不等於只能合併 252 格。

## 把主公式逐段拆開

=　開頭等號讓 Excel 把後面的內容視為計算公式。

TEXTJOIN　本課唯一使用的函數名稱，拼字須完整，不含空格。

( )　成對半形括號包住所有參數；最後一定要有右括號。

"、"　雙引號裡的頓號是結果中的分隔符號；公式外層仍用半形逗號分參數。

TRUE　表示略過真正空白的儲存格，不是要合併的姓名文字。

A2:A8　冒號表示從 A2 到 A8 的連續七格，兩端都包括。

,　半形逗號分開不同參數；引號裡的符號則是文字本身。

使用半形 = ( ) , : 及雙引號；文字使用直式雙引號 " "。部分地區設定以分號分隔引數，請依 Excel 的輸入提示調整。

## Excel 如何得到這個答案

1. 由 A2 開始收集小安，再讀 A3 小柏，兩者中間插入一個頓號。

2. A4 空白且第二參數是 TRUE，所以略過；接著把 A5 小晴與 A6 小岳依序加入。

3. A7 同樣略過，最後加入 A8 小寧。五個名字之間共四個頓號，得到主題答案。可以逐一指向 A2、A3、A5、A6、A8，邊讀邊在答案中核對。每個非空來源恰好出現一次，才能排除漏人、錯位或重複抄寫。

## 資料型態與邊界情況

- 一格裡若只有空格，仍是文字內容，不等於真正空白。略過空白的設定不會替你清除姓名前後的多餘空格。

- 結果是文字摘要，名稱重複也會照樣保留；本課函數負責合併，不會自行辨識兩個同名者是否同一人。若想知道有幾個人，不能只數字串中的文字長度；本課只完成整串名單，並沒有計算人數或驗證身分。

- 結果字串超過儲存格可容納的 32,767 個字元會顯示 #VALUE!；大型名單應分批整理。

## 同一個函數的延伸用法

以下例子彼此獨立。每做一題前，先還原上方的原始資料，再執行該題設定；不要沿用上一題的修改。

### 用法 1　改用斜線分隔

先恢復原始 A1:A8，保持 A4、A7 空白，在 E2 輸入下式。

```excel
=TEXTJOIN(" / ",TRUE,A2:A8)
```

結果：小安 / 小柏 / 小晴 / 小岳 / 小寧

分隔文字是空格、斜線、空格三個字元。

空白格仍略過，五個名字順序不變，只改變名字間的外觀。

### 用法 2　保留空白位置

先恢復原始 A1:A8，在 E2 輸入下式。

```excel
=TEXTJOIN("、",FALSE,A2:A8)
```

結果：小安、小柏、、小晴、小岳、、小寧

FALSE 讓 A4、A7 也保留各自的位置，七個位置之間共有六個頓號。

空白位置前後相鄰的頓號會連在一起，因此小柏及小岳後各出現兩個頓號。

## 常見錯誤

1. 名單中出現奇怪的間隔

原因：原本應留白的 A4 或 A7 含有空格。　處理：選取 A4、A7 分別按 Delete，再核對第二參數為 TRUE。

2. 只看得到部分姓名

原因：E 欄太窄，或鄰格內容擋住文字延伸。　處理：拉寬 E 欄或開啟自動換列；點 E2 查看公式列，勿因畫面截斷而刪掉姓名。

3. 顯示 #NAME? 或 _xlfn.TEXTJOIN

原因：可能使用未提供此函數的舊版本，或名稱拼錯。　處理：先確認拼字，再改用支援版本開啟；舊版不會因按特殊快捷鍵就取得新函數。

## 自己練習與完整解答

先遮住解答，試著自己輸入公式並預測結果。每題都從上方原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　不放分隔符號

先恢復原始 A1:A8，在 E2 合併五個姓名，中間不要任何符號。

答案公式：

```excel
=TEXTJOIN("",TRUE,A2:A8)
```

正確結果：小安小柏小晴小岳小寧

解答 1　第一參數用空字串 ""，不是空格。

解答 2　空白格略過，五個名字直接相連。

### 練習 2　只合併前段

先恢復原始 A1:A8，在 E2 只合併 A2:A5，用頓號且略過空白。

答案公式：

```excel
=TEXTJOIN("、",TRUE,A2:A5)
```

正確結果：小安、小柏、小晴

解答 1　範圍只有四格，其中 A4 空白，留下三個名字。

解答 2　依原順序加入兩個頓號，答案為小安、小柏、小晴。

### 練習 3　補上一名成員

先恢復原始 A1:A8，只在 A4 輸入「小禾」，在 E2 使用主公式。

答案公式：

```excel
=TEXTJOIN("、",TRUE,A2:A8)
```

正確結果：小安、小柏、小禾、小晴、小岳、小寧

解答 1　A4 現在有文字，會接在小柏之後；A7 仍然略過。

解答 2　六個名字之間有五個頓號，核對小禾沒有被移到最後。
