本教學由作者茂伯編寫，並由作者在 Windows 版 Microsoft 365 與 Excel 2021 實際操作驗證。

學會移除文字前後的半形空格，並把中間連續空格縮成一個。本課用品項名稱，說明結果為何仍保留字詞間隔；完成後，你能保留原文並核對整理結果，也知道網頁的不換行空格可能保留，不能把 TRIM 當成清除所有不可見字元的工具。

## 適用版本

適用 Microsoft 365 與 Excel 2016 至 2024

## 用途

- 整理人工輸入的英文品項名稱時，去掉開頭與結尾誤按的空白，並把中間連按數次空白鍵的地方縮成一次，讓同樣的名稱更容易核對。

- 合併不同人提供的文字清單前，先在獨立欄位整理一般空格，保留原文供追查。若資料來自網頁或特殊系統，還要確認空格是否為本函數處理的類型。

## 先準備範例資料

開啟空白活頁簿，依下表輸入。英文字母是欄，數字是列；例如 B2 就是 B 欄第 2 列。標題從 A1 開始，結果另外放在 E2。

| 列 | A | B |
| --- | --- | --- |
| 1 | 項目 | 原始文字 |
| 2 | 品項甲 | ␠␠Blue␠␠␠Pen␠␠ |
| 3 | 品項乙 | Red Pen |
| 4 | 品項丙 | ␠␠␠Pencil |
| 5 | 品項丁 | Eraser␠␠␠ |
| 6 | 品項戊 | A␠␠␠␠B |
| 7 | 品項己 | ␠␠文具␠␠␠清單␠␠ |
| 8 | 品項庚 | Notebook |

表格中的 ␠ 代表一個半形空格，只是顯示記號；輸入資料時請按空白鍵，不要輸入 ␠ 字元。

- 在 A1:B8 建立原表，所有指定空格都用半形空白鍵。B2 的精確輸入順序是：空白鍵 2 次、Blue、空白鍵 3 次、Pen、空白鍵 2 次；不要輸入任何引號。

- B3 是 Red、1 個空格、Pen，沒有前後空格。B4 是 3 個前方空格後接 Pencil，沒有尾端空格；B5 是 Eraser 後接 3 個空格，沒有前方空格。

- B6 是 A、4 個空格、B，前後沒有空格。B7 是前方 2 個空格、文具、中間 3 個空格、清單、尾端 2 個空格；B8 只有 Notebook，完全沒有空格。

- 需要看清空格時，選取該格後點公式列，移動插入點核對位置；不要把說明用的「空格」兩字打進資料。來源 B 欄與結果 E2 分開，避免原文被覆蓋。

## 輸入這個公式

```excel
=TRIM(B2)
```

輸入位置：E2　　正確結果：Blue Pen

建議順序：先照做並核對畫面，再看公式拆解，最後完成延伸用法與練習。所有練習各自從這一頁的原始資料開始。

## 照著做並核對畫面

名稱方塊在公式列左側，會顯示 A1 或 E2 等位置；公式列則是 fx 右邊顯示公式的長欄位。下列步驟都在工作表內操作。

1. 在空白工作表選 A1，建立 A1:B8。先照資料說明逐格輸入；B2 前方按 2 次空白鍵，中間按 3 次，尾端按 2 次，空格數不能憑表格寬度猜測。

2. 點 B2 的公式列檢查原文字，確認 Blue 與 Pen 的大小寫正確。再核對 B4、B5、B6、B7 的指定空格，不要先手動把它們清乾淨。

3. 在 E1 輸入「整理後文字」，選取 E2 並保持通用格式。B 欄原文不修改，這樣可以回頭確認處理前後的差異。

4. 點 E2 的公式列，輸入 =TRIM(B2)，只引用 B2，不加逗號或額外參數；左右括號使用半形，檢查後按 Enter。

5. 重新選 E2，應顯示 Blue Pen；點公式列確認仍為 =TRIM(B2)。結果前後沒有空格，中間保留 1 個半形空格，B2 原始多餘空格仍保留。

## 對照畫面確認結果

- B2 看起來與一般文字接近，但資料說明明確列出前 2、中 3、後 2 的空格數；畫面留白本身不足以判斷原始字元。

- E2 的 Blue Pen 中間還有一個空格，這是正確結果。TRIM 不會將字詞直接黏成 BluePen。

- 公式列的 =TRIM(B2) 表示結果跟隨原文更新，並非手動重打的乾淨文字；來源與結果應分別留在 B2 與 E2。

## 語法與引數

```excel
=TRIM(text)
```

引數就是交給函數處理的資料或設定。語法中的 [ ] 表示可以省略，輸入公式時不要打出方括號或省略號。

text　必要且唯一的參數，要整理一般空格的文字。本課引用 B2；也可在公式中直接輸入加半形雙引號的文字。函數不提供「刪除全部空格」或「只刪尾端」的第二個選項。

## 把主公式逐段拆開

=　表示計算公式；若只輸入 TRIM(B2) 而沒有等號，就不會執行。

TRIM　清除文字前後的 ASCII 半形空格，並將中間連續同類空格縮成一個。

B2　引用含多餘空格的原始文字，不必在儲存格參照兩側加引號。

( )　一對半形括號包住唯一參數，本式沒有逗號、範圍或其他函數。

使用半形 = ( ) , : 及雙引號；文字使用直式雙引號 " "。部分地區設定以分號分隔引數，請依 Excel 的輸入提示調整。

## Excel 如何得到這個答案

1. 先從 B2 讀取整段原文：前方 2 個空格，Blue，中間 3 個空格，Pen，尾端 2 個空格。字母大小寫保持原樣。

2. 移除 Blue 前方的 2 個一般空格，並移除 Pen 後方的 2 個一般空格；文字本身不會被刪除。

3. Blue 與 Pen 中間原有 3 個連續一般空格，整理成 1 個，保留兩個詞之間的分隔。

4. E2 得到 Blue Pen，前後無空格，中間恰好 1 個。B2 不會自動被修改，後續需使用整理結果時應引用 E2。

## 資料型態與邊界情況

- 本函數針對 ASCII 代碼 32 的半形空格。中文輸入法產生的全形空白、定位字元與其他不可見字元，不能一律假定會被清除。

- 網頁常見的不換行空格是另一個字元，代碼 160；單用 TRIM 不會移除它。外觀像空白但仍保留時，要先查清字元來源，而不是認定公式壞了。

- 原文已只有正常單一空格時，結果不變；只有一般空格的文字會變成空字串。這是公式回傳沒有可見文字，不等於來源格被清空。

## 同一個函數的延伸用法

以下例子彼此獨立。每做一題前，先還原上方的原始資料，再執行該題設定；不要沿用上一題的修改。

### 用法 1　只刪前方空格

先恢復原始 A1:B8，確認 B4 前方有 3 個半形空格；E1 保留原標題，在 E2 改引用 B4。

```excel
=TRIM(B4)
```

結果：Pencil

B4 前方 3 個空格會被移除，Pencil 的字母維持不變。

原文沒有中間或尾端空格，所以結果就是 Pencil，沒有額外增加字元。

### 用法 2　中文字詞之間

先恢復原始 A1:B8，確認 B7 前後各 2 個、中間 3 個半形空格；E1 保留原標題，在 E2 引用 B7。

```excel
=TRIM(B7)
```

結果：文具 清單

前後的一般空格被移除，中間 3 個縮成 1 個。

結果是文具與清單中間保留一格，不是四個中文字全部連在一起；中文內容也遵守相同空格規則。

## 常見錯誤

1. 結果仍有 Blue 與 Pen 之間的空格。

原因：把「整理空格」誤以為刪除每一個空格。　處理：本課正確結果就是 Blue Pen；中間一格應保留，不要把它當成失敗。

2. 網頁貼來的空白完全沒有消失。

原因：可能是不換行空格或其他非 ASCII 32 的字元。　處理：先保留來源並確認字元類型；本課可重新用半形空白鍵輸入同樣資料驗證，不能承諾 TRIM 會清除所有空白。

3. 主題結果看不出任何變化。

原因：原文可能在輸入時已沒有指定空格，或 E2 直接引用原文而未用 TRIM。　處理：依資料說明重新建立 B2 的前 2、中 3、後 2 個空格，再確認公式列為 =TRIM(B2)。

## 自己練習與完整解答

先遮住解答，試著自己輸入公式並預測結果。每題都從上方原始資料重新開始，結果放在題目指定的儲存格。

### 練習 1　整理中間多空格

先恢復原始 A1:B8，確認 B6 是 A、中間 4 個半形空格、B；E1 保留原標題，在 E2 引用 B6。

答案公式：

```excel
=TRIM(B6)
```

正確結果：A B

解答 1　原文前後沒有空格，所以只需整理中間連續的 4 個空格。

解答 2　E2 得到 A B，中間恰好 1 個；不能寫成無空格的 AB。

### 練習 2　只有一般空格

先恢復原始 A1:B8；將 B2 內容清除後，按半形空白鍵 3 次並按 Enter。E1 保留原標題，在 E2 使用主公式。

答案公式：

```excel
=TRIM(B2)
```

正確結果：（空白）

解答 1　B2 現在只有 3 個一般空格，經整理後沒有任何可保留的字詞。

解答 2　結果是空字串，E2 看起來空白但仍有公式；重新選 E2，公式列應保留 =TRIM(B2)。

### 練習 3　不換行空格不會消失

先恢復原始 A1:B8；複製下列方括號內的完整內容到 B2，不要複製方括號：[ Blue Pen ]。三個空白都是代碼 160 的不換行空格，前、中、後各 1 個。E1 保留原標題，在 E2 使用主公式。

答案公式：

```excel
=TRIM(B2)
```

正確結果：[ Blue Pen ]（方括號僅標示文字邊界）

解答 1　本題的三個空白不是按一般空白鍵產生的 ASCII 32；請直接複製指定內容，勿手動換成普通空格。

解答 2　TRIM 不移除這三個不換行空格，結果與 B2 相同。這是在驗證限制，做完後恢復原始 B2，主例才能得到 Blue Pen。
