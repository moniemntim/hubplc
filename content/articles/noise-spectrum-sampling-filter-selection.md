## 先用用途決定「可接受的錯」

同一個類比值可同時服務趨勢圖、操作員顯示與保護邏輯，但三者不該因為都嫌畫面跳動就共用同一個濾波結果。這篇只處理一件事：在固定 **100 Hz**（每筆 10 ms）的資料上，選五點或十一點等權移動平均時，數字會怎麼變、會晚多久、又會漏掉什麼。

下列資料與結論都是離線合成算例，沒有接 PLC、ADC、感測器或現場設備實測；五點、十一點也不是任何廠牌的預設參數。實際模組的取樣週期、內建濾波位置、缺樣行為與安全用途，必須依該模組文件及現場驗證決定。

先把需求寫成可驗證的句子。例如：

| 用途       | 要保留的現象     | 不能接受的代價             |
| ---------- | ---------------- | -------------------------- |
| 趨勢畫面   | 秒級變化         | 本示例需求允許顯示晚 50 ms |
| 操作員顯示 | 操作後的階躍     | 100 ms 後仍看不出已變化    |
| 事件判定   | 單筆、短暫的突波 | 被平滑成沒有事件           |

若需求是判定短暫事件，先保留原始值並在原始路徑判定；平均值可以做顯示或輔助分析，不能取代事件證據。已發布的[原始值、品質與超量程處理](/articles/analog-raw-quality-filter-overrange)說明 Bad／缺樣不要當作零；[濾波後尖峰回查](/articles/filtered-peaks-raw-data-traceability)則說明如何把畫面數值追回原始序列。

## 算例的規則與兩個固定數字

本篇的移動平均採用「包含目前這一筆」的尾端窗口：

`y[k] = (x[k] + x[k-1] + ... + x[k-(N-1)]) / N`

剛啟動、窗口還沒滿時，這裡一律標示 **初始化中，不輸出平均值**；不是補零，也不是把兩筆硬除以五。以下序列都假定窗口已由已知的舊資料填滿，才能重現相同答案。時間以最後一筆舊值的記錄點 t=0 起算，第一筆新值在 t=10 ms；這不是已量到的物理階躍施加時間。若從第一筆新樣本起算，五點與十一點完全換新分別是40與100 ms，不能把不同起點混用。

| 窗口 N | 每筆時間 | 名義群延遲 `(N-1)/2 × 10 ms` |   窗口完全換成新值的時間 |
| -----: | -------: | ---------------------------: | -----------------------: |
|      5 |    10 ms |                        20 ms |   50 ms（第 5 筆新樣本） |
|     11 |    10 ms |                        50 ms | 110 ms（第 11 筆新樣本） |

「群延遲」描述線性相位 FIR 對緩慢、可視作波形整體的時間位移；它不是階躍抵達最終值的時間。對階躍和短脈衝，下面的逐筆序列才是選型要看的數字。

## 例一：10 單位階躍，五點平均多久才追上？

假設舊值連續五筆都是 0，接著輸入永久變為 10。五點窗口逐筆替換一個舊 0：

| 新樣本序號 | 窗口內容           | 五點平均 |
| ---------: | ------------------ | -------: |
| 1（10 ms） | 0, 0, 0, 0, 10     |        2 |
| 2（20 ms） | 0, 0, 0, 10, 10    |        4 |
| 3（30 ms） | 0, 0, 10, 10, 10   |        6 |
| 4（40 ms） | 0, 10, 10, 10, 10  |        8 |
| 5（50 ms） | 10, 10, 10, 10, 10 |       10 |

所以五點平均在 20 ms 時是 4，並不是「延遲 20 ms 後突然變成 10」；第 5 筆才完全追上。若操作員畫面要求「50 ms 內至少看見一半變化」，此例在第 3 筆（30 ms）才到 6，需求是否通過要由原先定義決定。

十一點的同一個階躍更直觀：第 `j` 筆新樣本（j = 1 到 11）的結果是 `10 × j / 11`。因此第 1、5、6、11 筆分別為 0.909、4.545、5.455、10；在 50 ms（第 5 筆）仍不到一半，在 60 ms 才超過一半，110 ms 才完全換新。這是十一點換來更平順時，明確付出的反應時間。

## 例二：只有一筆的 10 單位脈衝，平均後還剩多少？

現在輸入原本全為 0，只在一筆出現 10，下一筆立刻回到 0。五點窗口包含那筆脈衝的五個輸出都等於：

`(10 + 0 + 0 + 0 + 0) / 5 = 2`

也就是原始路徑有一筆 10，五點平均路徑卻得到連續五筆 2，若每筆保持10 ms顯示則持續50 ms（首末非零取樣點相距40 ms）；脈衝不只變矮，也被拉寬。十一點則是連續十一筆 `10 / 11 = 0.909`，以相同保持顯示方式持續110 ms（首末點相距100 ms）。若事件門檻是 5，兩種平均都完全不會觸發，雖然原始值 10 明確超過門檻。

這個算例不能推導出「所有短脈衝都應視為雜訊」。它只證明：在這個固定定義下，等權平均會改寫脈衝的高度與時間形狀。若那一筆代表安全或品質事件，事件判斷要走原始資料或另經需求驗證的專用邏輯。

## 例三：平穩訊號上的獨立雜訊，到底少多少？

若雜訊樣本可合理近似為彼此獨立、平均值為零、每筆標準差為 1，等權 N 點平均的標準差是 `1 / √N`。在這個前提下：

| 方法       | 輸出標準差 | 相對於原始值 |
| ---------- | ---------: | -----------: |
| 原始值     |      1.000 |         100% |
| 五點平均   |      0.447 |        44.7% |
| 十一點平均 |      0.302 |        30.2% |

這不是現場保證。相鄰樣本若相關、存在慢漂移、週期干擾或缺樣，實際降低量會不同。量測驗收時應保存原始序列，分開計算穩定區段的散布、階躍序列與必須保留的短事件；不要只以「畫面變平」作為通過條件。

## 選五點、十一點前的實作檢查

1. 量到實際的輸入取樣間隔。100 Hz 只是本篇例子；若資料每 20 ms 才到一次，從最後舊值到第五筆新值為100 ms，而五個取樣點首末相距80 ms。
2. 對固定基線輸入，記錄原始與濾波值的散布。先確認要降低的是隨機雜訊，不是漂移或真實製程變化。
3. 用已知階躍，列出每一筆輸出，核對「首次可見、超過門檻、完全到達」分別在哪一筆。
4. 用最短仍需被偵測的脈衝，核對原始與濾波路徑是否各自符合用途。
5. Bad、遺失、時間倒退或設定版本改變時，明定停止輸出、重建窗口或標示初始化中的規則；不要讓缺值以零加入平均。

## 取樣與頻譜的邊界

濾波選型不能跳過取樣位置。類比到數位轉換之前，前端頻帶限制用來避免不需要的高頻在取樣時折返；數位資料要降採樣時，也必須在抽點前先限制新取樣率容許的頻帶。這一篇不重講混疊公式與頻率驗證流程，請接著看[取樣頻率不足如何辨識混疊](/articles/sampling-aliasing-frequency-validation)。

Analog Devices 的 MT-002 也指出，輸入訊號通常在 ADC 前經過信號調理與濾波，目的是移除關注頻帶外的訊號並避免混疊；同時，濾波器的過渡帶與所需衰減會影響設計取捨。[來源：Analog Devices MT-002](https://www.analog.com/media/en/training-seminars/tutorials/MT-002.pdf)

## 把選擇寫成可重算的驗收條件

對 100 Hz 的五點／十一點等權平均，這篇已給出可重算的數字：名義群延遲為 20／50 ms，10 單位階躍完全到達為 50／110 ms，單筆 10 的脈衝會被攤成 5 筆 2／11 筆 0.909。選哪一個，取決於你事先寫下的可接受散布、可接受反應時間，以及短事件是否必須保留。

把原始值、濾波值、品質旗標、實際時間戳與設定版本一起記錄，才可以在驗收失敗時重算原因，也能避免把合成範例誤當成已完成的設備實測。
