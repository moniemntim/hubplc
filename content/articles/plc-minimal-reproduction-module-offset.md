## 先交出別人能重播的錯誤

「第二個模組資料偏了」還不足以重現。最少要交出原始資料、映射起點、預期值和錯誤值，而且每個通道用不同數字。本篇固定六筆資料，先讓接手者看到同一個錯誤，再討論如何縮小真正的 PLC 專案。

**附件已執行的是 Node.js 合成陣列案例，不是 PLC 工程檔。**沒有連接兩個實體模組，也未在 CODESYS 或 GX Works 編譯；這個界線要跟著交接資料保留。

## 下載並執行

下載 [reproduce.mjs](/examples/plc-mapping/reproduce.mjs) 與[交接單](/examples/plc-mapping/handoff.md)。程式只需單一檔案和 Node.js 22.13.0 以上，不依賴套件。在檔案所在資料夾執行：

```powershell
node --version
node reproduce.mjs
```

它輸出兩列 JSON，再印出 PASS。PASS 只表示指定錯誤已重現、修正後符合兩組答案且基本越界檢查有效；不是硬體驗收通過。

## 六個值怎麼分成兩個模組

本例自訂應用程式陣列格式：A 四個值、B 兩個值，零起算、每通道恰好佔一個元素，沒有填補欄位或狀態字。

| 標籤 | 索引 | 第一組值 | 第二組值 |
| --- | --- | --- | --- |
| A.CH1 | 0 | 101 | 111 |
| A.CH2 | 1 | 202 | 222 |
| A.CH3 | 2 | 303 | 333 |
| A.CH4 | 3 | 404 | 444 |
| B.CH1 | 4 | 505 | 555 |
| B.CH2 | 5 | 606 | 666 |

這裡的 4 來自**已明訂的陣列配置**，不能用「前一模組有四個通道」推論真實 PLC 第二模組位址也是 4。真實裝置可能有狀態字、不同資料寬度或獨立位址，須由組態與手冊確認。

映射做兩次讀取：B.CH1 取 raw[start]、B.CH2 取 raw[start+1]。把 start 誤設成 2，就把 A.CH3、A.CH4 當成 B 的資料。

## 核對兩組輸出

| 序號 | 錯誤起點 2：B.CH1 / CH2 | 正確起點 4：B.CH1 / CH2 |
| --- | --- | --- |
| 17 | 303 / 404 | 505 / 606 |
| 18 | 333 / 444 | 555 / 666 |

原始 raw 在兩次映射中不變，差異只來自 start。兩組不同值都出現相同偏移，支持本案例的索引錯誤結論。若六個值全部填 0，錯誤與正確映射就得到相同結果，無法抓出問題。

練習時把第二組六個值換成另一組互不相同的值，並更新 expected 的最後兩個通道答案，重跑後仍應先重現錯誤、再通過正確映射。只改 expected 讓錯誤起點通過，是改掉驗收條件，沒有修正映射。

## 帶回 PLC 專案：縮小又保留現象

保存原案，在副本套用同一組可辨認的測試值，記錄原始、映射及顯示三層。只有副本能重現後，才逐項移除無關流程；每移除一項就重跑。若錯誤消失，恢復剛移除的項目，保留它作為必要條件。

保留 CPU／模組型號、排列、資料型別、映射表、必要任務及函式庫。不能換成通道數相似的裝置，仍宣稱重現同一個硬體問題。

| 證據 | 先查哪一層 |
| --- | --- |
| 原始資料已與通道不符 | 模組組態、模式與 I/O 映射 |
| 原始正確，映射後固定錯兩格 | 索引、複製範圍、資料寬度 |
| 原始與映射正確，畫面仍是上一筆 | 顯示來源、快取及更新時序 |
| 各層取自不同時間 | 先取得可關聯的快照，再判偏移 |

相同序號有助追蹤，卻不會自動讓多任務讀取變成一致快照。本附件一次處理完整陣列，沒有模擬跨任務競爭；真實專案須用平台支持的方法確認一致性，不能用同一張監看畫面代替。

## 最後一步是換環境重播

交接單把 Node 案例與真正的 PLC 工程專案分開。後者至少要讓接手人能開啟、編譯、注入同一組資料，保留實際結果。

若使用 CODESYS，由 **File → Project Archive → Save/Send Archive** 整理專案，可把測試資料及交接說明加入 Additional Files。檢查必要裝置與函式庫是否真的包含；歸檔成功仍不等於接手環境能重播。[官方 Project Archive 說明](https://content.helpme-codesys.com/en/CODESYS%20Development%20System/_cds_saving_project_archive.html)

本站目前提供可獨立重播的邏輯案例。模組上電、無效品質、首次更新與真實位址，仍須在工程專案補測。
