# 寫文章指南

複製 articles/first-article.md，改成英文檔名，例如 mitsubishi-timer.md。

保留最上方兩行 --- 包住的資訊。填入標題 title、簡介 description、日期 date（YYYY-MM-DD）與作者 author；每個欄位使用單行文字。

正文寫在第二行 --- 之後。使用 ## 小標題、一般段落、- 清單，以及 Markdown 的程式碼區塊與圖片語法。

圖片放在 public/images/，文章用 ![圖片說明](/images/檔名.png) 引用。

draft: true 是草稿，不會出現在網站。完成後改成 draft: false，提交至 GitHub main 分支，Cloudflare 就會重新組建網站。

每篇已發佈文章都有自己的網址 /articles/英文檔名/，以及獨立的標題與簡介。

## 分類、標籤與閱讀目錄

文章列表提供搜尋、主題分類、排序、列表／卡片切換，每頁顯示 12 篇。搜尋會查標題、摘要、標籤及正文；網址會保留搜尋與分頁條件。

可在最上方資訊區塊加入以下選填欄位，仍使用單行文字：

```text
category: 工業通訊與網路
tags: Modbus, RS485, Q 系列
```

建議分類：PLC 程式與控制、工業通訊與網路、感測器與量測、電氣介面與配線、HMI 畫面與操作、資料記錄與報表、維護與故障排查。沒有填寫時會依標題及檔名自動歸類；若自動分類不合適，填入 category 即可覆寫。tags 使用逗號分隔，不使用多行 YAML 陣列。

正文的 `##` 與 `###` 標題會自動產生章節目錄與定位連結，重複標題也有不同定位點。閱讀時間是依篇幅估算。相關文章會依同分類與共同標籤選取最多三篇。

索引和目錄會在開發或建置前自動產生；請修改 Markdown 來源，不要編輯 generated JSON 或自動產生的文章頁。

目前沒有後台登入介面。你也可以直接把文章內容交給 Codex 協助排版後更新。
