# 寫文章指南

複製 articles/first-article.md，改成英文檔名，例如 mitsubishi-timer.md。

保留最上方兩行 --- 包住的資訊。填入標題 title、簡介 description、日期 date（YYYY-MM-DD）與作者 author；每個欄位使用單行文字。

正文寫在第二行 --- 之後。使用 ## 小標題、一般段落、- 清單，以及 Markdown 的程式碼區塊與圖片語法。

圖片放在 public/images/，文章用 ![圖片說明](/images/檔名.png) 引用。

draft: true 是草稿，不會出現在網站。完成後改成 draft: false，提交至 GitHub main 分支，Cloudflare 就會重新組建網站。

每篇已發佈文章都有自己的網址 /articles/英文檔名/，以及獨立的標題與簡介。

目前沒有後台登入介面。你也可以直接把文章內容交給 Codex 協助排版後更新。
