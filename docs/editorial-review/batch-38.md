# 第三十八批：117 篇公開內容證據重審

日期：2026-10-16。本批逐篇重新核對目前117篇 `reviewed-local` 公開文章，範圍包含讀者任務是否獨立、固定輸入與預期結果、外部來源、可下載附件、軟體／設備版本、操作截圖、執行紀錄，以及是否有原廠模擬器或實體設備證據。

## 觀察結果

- 117篇都有可辨識的獨立讀者任務；相近主題仍須依正文與讀者成果人工判斷，不能只用相似度分數合併或下架。
- 未發現把PLC、HMI或硬體直接冒稱為「已實測」的公開文章。文內的「已執行」多數明確限定為瀏覽器、Node.js、SQLite或離線資料模型。
- 117篇的 `hardwareVerified` 皆為 `false`；沒有文章附上足以證明PLC／HMI／現場設備完成測試的型號、韌體、接線、原始量測與結果紀錄組合。
- `xca-ecu-https-certificate-setup` 有19張實際XCA與Windows操作截圖，但未記錄XCA／Windows完整版本，也未證明ECU端已部署憑證並完成HTTPS連線。
- `latency-injection-timeout-retry` 保存Windows與Node.js 24.19.0的本機HTTP延遲執行紀錄；這是本機軟體測試，不是PLC或網路設備實測。
- 其餘文章的證據主要是可下載的Node.js／瀏覽器案例、固定fixture、離線算術、官方文件或待填寫驗收表。沒有證據的項目維持「未實測／未驗證」，不得改成「已實測」。

## 日期核對

Git首次加入紀錄只能證明61篇於2026-09-17、55篇於2026-09-21、1篇於2026-10-07加入；範圍為21天，不能誠實改寫成完整一個月。網站改為分開呈現可追溯的初次發布日與實質更新日，並在sitemap輸出文章 `lastmod`，不以虛構日期分散發布量。

## 本輪處理

- 新增 `content/article-dates.json`，保存每篇的Git首次加入日、最近內容提交日及來源commit。
- 公開文章頁新增「本頁證據與限制」，顯示全量複核日期、設備實測狀態、截圖數量及台帳中的實際核對項目。
- 文章頁加入TechArticle結構化資料，分開輸出 `datePublished` 與 `dateModified`；文章目錄以「發布／更新」正確標示日期。
- 產製流程要求每篇公開文章都要有日期來源、`reviewed-local` 台帳及匹配的SHA-256，避免未審查或已變更內容無意間公開。

本輪沒有新增硬體或原廠模擬器測試，也沒有改寫任何文章為「已實測」。實際設備證據需由後續受控測試提供完整型號、版本、接線／條件、原始結果與日期後才能變更狀態。
