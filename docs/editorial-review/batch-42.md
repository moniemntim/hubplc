# 第四十二批：公開內容與導覽修正

日期：2026-10-21。本批檢查目前公開的 53 篇文章（3 篇工業文章、50 篇 Excel 教學）、文章與課程入口，以及工具頁的連結和顯示。原稿總數與公開資格不變。

## 問題與修正

- PLC／工程文章目錄仍固定推薦 RS485、計時器等已無公開搜尋結果的主題。改以目前公開文章的索引欄位篩選建議詞，搜尋提示同步更新；沒有可用建議時不顯示主題按鈕。
- 15 篇 Excel 網頁仍以「第一頁」指稱原始資料，改為「上方」。ABS 練習改為指向實際的 B5；SUBSTITUTE 改為指向存在的「用法 1」。合計修改 16 篇文章。
- 首頁課程數量原為固定 50，改為依課程清單與公開文章的交集計算；沒有公開課程時不顯示推廣入口。課程首頁的開始連結改為顯示首個公開課程的實際課號。

## 內容核對與證據界線

- 逐一核對 16 篇文章的完整差異，確認僅有上述指引文字替換；公式、資料表、練習結果與發布／更新日期維持原紀錄。
- 更新前核對各原稿與原台帳 SHA-256 相符，再登錄本批審查日期、雜湊與變更說明。作者驗證來源及公開資格保持原紀錄；本輪沒有重新執行 Excel、PLC 或 ECU 實機測試。
- 抽查 SUMPRODUCT、FILTER、AVERAGEIFS、MINIFS、MAXIFS 的主例與練習計算；未將抽查結果視為全課程的實際 Excel 操作驗證。
- 建置輸出的 144 個 HTML（包含範例附件及 404）掃描到 3,507 個連結與 85 張圖片；未發現缺少的本機資源、失效的本機章節定位、重複 ID、空白標題或圖片尺寸不符。外部參考網站的可用性不在此結論內。
