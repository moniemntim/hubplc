# 第四十三批：公開頁面視覺與響應式排版

日期：2026-10-21。本批延續內容檢查，改善首頁、文章目錄、Excel 課程、閱讀頁與共用導覽的視覺層次。沿用原有灰白背景與深綠配色，沒有新增套件、外部字型或圖片服務。

## 問題與修正

- 首頁原先以相近的文字與白色卡片排列，缺少清楚的首要操作。加入工具箱／文章入口及靜態類比換算範例，並以目前公開清單顯示工具、文章與課程數量。範例清楚標示為「換算範例」，不是即時設備數值。
- 部分 H2／H3 沿用一般字重，章節層次不明顯。統一標題字重，整理首頁卡片、課程階段、長文 H2／H3、內文行距、目錄與圖片邊界。
- 搜尋、分類與結果控制的視覺分組較弱；手機標題容易留下單字斷行。調整文章目錄的搜尋區、按鈕、分類選取、日期分隔及窄螢幕標題換行。
- 英文導覽在 481px 寬度會超出視窗。提前至 600px 以下使用換行的全寬導覽，並補九種寬度的英文回歸檢查。
- 短表格的白色背景原本延伸到表格內容之外；改將白底放在儲存格，保留表格橫向捲動。

首頁樣式移至 `app/home.css`；既有內容修正、文章公開資格、作者驗證與日期紀錄均保留。
