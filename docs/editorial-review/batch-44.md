# 第四十四批：案例入口與重疊工具整改

日期：2026-10-31。本批依使用者「針對缺乏價值的內容實際整改，修正案例呈現和工具頁重疊的問題，檢查後發布」指示執行。以下記錄實際發現與修正；AdSense 畫面沒有提供個別違規網址，不能將本批發現當作 Google 已確認的內部判定原因。

## 已確認的問題與處理

- 首頁的代表教學清單原本全是暫停公開的文章，經公開清單篩選後整個區塊不會出現。改用目前公開的 FX5U BIN、CSV 與 XCA／ECU HTTPS 三個完整案例，在工具清單之前呈現問題、操作順序、完成判準及文章入口；文章目錄增加對應的兩條工作路徑。
- 15 個交流電力與 3 個能耗頁面只套用共用計算器的預設值，獨立內容與操作差異不足。移除這 18 個公開頁面，整併至交流功率、能耗與電費兩個主工具。工具目錄從 75 個減為 57 個；sitemap 從 134 個網址減為 116 個；建置含 404 共 117 條路由。
- 舊網址使用單次 308 轉址，帶入 allowlist 的 `task` 預設；原有 7 個別名也直接指向主工具，避免兩次轉址。共 25 個舊路徑，含尾斜線共 50 個入口。保留其他查詢參數，固定原網址對應的 task；canonical 與 sitemap 均不含 task。內部保留舊 slug 的型別／說明資料相容性，沒有重新建立公開頁面。
- 保留 `/tool/va-to-amps`，因為它另有以相對中性線電壓計算的三相模式，與主交流工具使用線電壓的功能不同。新增明確連結說明電壓基準。
- 兩個主工具新增五個中英文教學案例：單相功率、平衡三相線電流、UPS 的 W／VA 雙重限制、按使用時數估算用電量、由累積電量反推平均功率。每例列出輸入來源、操作、預期數字、結果解讀及常見錯誤，並可直接帶入工具。手機表格轉為逐筆資料，標題與步驟保留清楚層次；案例可在沒有 JavaScript 時閱讀。
- 合併後仍可切換計算方向。能耗工具增加費率開關，保留舊「只算用電量／平均功率」入口不顯示費率的行為；停用費率時，先前無效的費率輸入不會阻擋能耗計算。載入範例會還原目前選取的案例或舊網址預設。

三個工程文章的實機紀錄仍是作者提供的驗證，未宣稱本站重新操作硬體。五個新算例使用明示的教學條件，未宣稱為現場量測。原有 53 篇公開文章、作者證據、來源雜湊、日期與下架條件均保留；沒有修改文章原始檔或批次恢復未驗證內容。
