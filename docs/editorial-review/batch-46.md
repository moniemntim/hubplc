# 第四十六批：57 個工具逐頁整改與日常工具

日期：2026-11-15。依使用者要求，實際檢查原有 57 個工具的功能重複、說明與案例，並加入參考站的工具類型。正式網域維持 hubplc.com。

- 49 個原工具新增各自的輸入來源、操作、預期結果、判讀與錯誤；6 個 PLC 與 2 個電力工具保留完整專用案例並重新驗證。逐頁記錄見 [稽核表](../tool-audit/2026-11-15/README.md)。
- 通用換算改為單筆流量與 13 類批次換算，最多 200 筆，保留原列號與錯誤，全部有效才可複製或交換。12 個單筆專頁維持獨立用途；既有電力整併與轉址維持。
- 修正非零數值下溢成零、換算中間值溢位／下溢、同溫標小數精度，以及金額小數位錯誤說明。
- 新增抽獎／抽籤、分組／配對、交換禮物、批次序號、測試資料、IP、個資遮罩、Email 格式與姓名拼音共 9 頁。密碼與世界時鐘沿用既有頁面；共 66 個工具、5 類。
- 抽籤使用 Web Crypto；交換禮物每人送收一次且不自抽。CSV 處理公式開頭字元；Email 僅做格式／IDN／重複檢查；拼音是可編輯漢語拼音草稿。測試資料標示 TEST- 與 example.invalid，並非真實身分。
- 日常工具不載入廣告；一般名單處理不主動連線上傳。IP 由使用者按鈕觸發本站 Cloudflare 連線資訊查詢，不持久保存結果；隱私頁同步說明。
- 53 篇公開文章及舊網址保留；沒有恢復公開驗證面板、沒有解鎖暫停公開文章，也不代送 AdSense 複查。
