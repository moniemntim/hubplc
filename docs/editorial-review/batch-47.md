日期：2026-11-15。依使用者要求，優先修正基礎換算與相似 Excel 課程，保留舊網址後發布。正式網域維持 hubplc.com；這是內容與功能整改，不代表 Google 已確認拒登原因或核准 AdSense。

## 1. 基礎換算頁具備不同的應用任務

保留原有快速換算及網址，12 頁各增加獨立輸入、計算、錯誤處理、公式、來源與兩個操作案例。通用頁仍負責流量單筆及同類物理量批次換算。

| 舊網址 `/tool/` 下的 slug | 新的應用任務                                 |
| ------------------------- | -------------------------------------------- |
| length-converter          | 圖面標稱、對稱公差及英吋上下限               |
| temperature-converter     | 溫度兩端、絕對溫度及溫差                     |
| pressure-converter        | 依明示大氣壓基準計算表壓與絕對壓             |
| angle-converter           | 編碼器計數、實現角度及量化誤差               |
| speed-converter           | 皮帶行程、節距間隔及理論通過率               |
| time-converter            | 班別可用時間、完整循環及剩餘時間             |
| mass-converter            | 扣除皮重及估算等效件數                       |
| area-converter            | 矩形用料、預留損耗及理論板數下限             |
| volume-converter          | 長方體槽容量、液位內容量及餘量               |
| power-converter           | 由扭矩、轉速及效率估算軸功率與輸入           |

| storage-converter         | 十進位／二進位容量、bit／byte 速率及傳輸時間 |

24 個案例都列齊實際 UI 欄位，中英文步驟可獨立操作。新增應用 CSV 與複製包含輸入及結果；無效或清空時不輸出舊結果。保留完整有效數值供匯出，畫面另做易讀格式。

邊界修正包含：面積／容量下溢、超大整數計數、超長傳輸時間、電容小數容差邊界，以及二進位小數造成多買一張板或少算一個循環。整張板材／完整循環使用十進位整數比例作進捨判斷。

## 2. 三組 Excel 課程改用不同工作情境

六篇舊網址、課程順序、原有基礎公式與圖片保留；原本相同骨架改成不同的資料、決策、錯誤與練習：

- MAXIFS：交班溫度峰值、並列、無資料與真實零值；MINIFS：排除故障零值及未完成紀錄的最短有效循環與樣本數。
- ROUNDUP：253 kg、12.5 kg 整包採購，21 包／262.5 kg／餘 9.5 kg；ROUNDDOWN：每件切斷都扣鋸縫，1800 mm、350 mm、3 mm 得 5 件／餘 35 mm。首端整平、最後一件切斷及非最佳化模型均明示。
- LARGE：壓力觀測值的並列高峰及有效名次；SMALL：以可查核輔助欄排除無效循環後取第 k 小值。

新例題經 Microsoft 官方函數說明、原始資料手算與 `tests/excel-distinct-lessons.test.mjs` 獨立計算核對。此環境未安裝原生 Excel，沒有宣稱新例題已用其引擎重新執行。ledger 將原作者實機聲明限於保留的基礎範例／截圖，另記本次離線核對、圖片 SHA-256 及 `nativeExcelRerun: false`。全課程首頁也移除涵蓋全部新案例的籠統驗證宣稱。

三組正文四詞片段 Jaccard 相似度由約 0.766／0.780／0.681 降至 0.042／0.050／0.067；這只用於檢查重複文句，並非 Google 的品質或核准門檻。

## 3. 時鐘案例能由訪客操作

世界時鐘改為暫停當下時刻、搜尋紐約、比較日期／時間／時差，再回台北恢復更新。移除訪客無法設定的固定測試時鐘。碼錶以實際開始、單圈與暫停操作解釋約 10／15 秒及累計約 25 秒，小數依按鍵時點而定。

## 4. 延伸實作連結確實公開可達

9 個工具頁共 10 個延伸連結，僅指向 8 篇已公開文章，包括 FX5U BIN、CSV、XCA 及五篇對應 Excel 課程。頁面顯示的任務有各自目的；未解鎖任何暫停公開文章，仍保留未來發布狀態過濾。PLC／Excel 文章未放回首頁或主選單。

## 5. 修正雜湊與亂數的絕對保證

雜湊改為原文改變通常會改變摘要，但碰撞仍可能存在，並附 NIST 定義。密碼／PIN 改為每次重新抽樣仍可能重複，不再保證每次不同。
