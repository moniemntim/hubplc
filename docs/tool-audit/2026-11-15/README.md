# HubPLC 工具逐頁整改記錄

日期：2026-11-15。原有 57 個工具全部逐頁檢查；另新增 9 個工具頁，合計 66 個工具、5 類。此記錄是網站功能與內容整改，不是 Google 對拒絕原因的確認，也不代表 AdSense 核准。

## 已實施

- 49 個原有頁面新增各自的用途、適用範圍、輸入來源、操作步驟、預期數值、結果解讀、常見錯誤及必要相關工具連結。6 個 PLC 工具與 2 個完整電力工具保留既有專用案例，重新驗證實際操作。新增 9 頁也提供同樣結構的獨立案例，合計 58 份新指南。
- 通用單位頁改為流量與批次工具：單筆僅流量，批次支援 13 類、最多 200 筆；保留原列號與錯誤，全部有效才可複製表格或交換方向。12 個單筆專頁保持各自用途，不再顯示相同的通用指引。既有電力整併與 25 組舊網址轉址維持。
- 修正非零極小值被解析成 0、線性換算經 SI 中間值造成可避免的溢位／下溢、同溫標換算精度流失，以及金額超過兩位小數的錯誤說明。
- 新增工具的輸入變更會清除舊結果；名單、個資與測試資料不主動上傳。日常與編碼分類不載入廣告。IP 查詢例外會經使用者按鈕向本站取得 Cloudflare 連線資訊，程式不保存結果。
- 站名與正式網域保持 hubplc.com；53 篇既有公開文章及舊網址保留，未恢復首頁文章入口、未公開暫停文章、未恢復公開編輯驗證面板。
